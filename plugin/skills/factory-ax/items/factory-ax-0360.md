# 숙련 작업자가 하던 반복 작업에 AI 로봇을 시험 적용(PoC)하는 제조 사업자는 처음부터 사람만큼의 처리량을 기대하지 말고, 중간 목표치와 추가 학습 기간을 계획에 넣어야 한다.

👤 출처 1곳 · 헬로티

한 제빵 공정 사례에서는 숙련 작업자가 시간당 약 600개를 처리하는 틀 제거 작업에 로봇을 시험하면서, 우선 목표를 시간당 300개로 잡았습니다. 발표 시점에는 이 목표에도 미치지 못해 추가 학습과 모델 조정을 이어 가고 있었습니다. 도입을 판단하기 전에 숙련자 처리량, 로봇의 중간 목표, 목표에 도달할 때까지 걸리는 학습 기간을 공급사와 미리 정해 두시기 바랍니다. 단일 사례이므로 우리 작업에서는 결과가 다를 수 있습니다.
