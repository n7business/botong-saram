# 우리 현장 작업자의 동작 데이터를 외부 업체에 맡겨 수집하는 제조 사업자는 그 데이터를 우리 회사 안에서만 쓸지, 업체가 다른 곳에 팔거나 재활용할 수 있는지를 계약서에 정해 두어야 한다.

👤 출처 1곳 · 헬로티

작업 방식이 경쟁력과 직결되는 업종에서는 데이터의 사용 범위와 접근 권한이 거래 조건을 좌우합니다. 기사 속 데이터 수집 업체는 맞춤형 학습 데이터 공급과 함께 장기적으로 데이터 거래 플랫폼을 통한 유통 확대를 계획하고 있습니다. 따라서 우리 공장에서 모은 데이터가 다른 고객에게 팔리지 않도록 소유권, 이용 범위, 제3자 제공 금지, 접근 권한, 계약 종료 후 삭제를 계약서에 명시하세요.
