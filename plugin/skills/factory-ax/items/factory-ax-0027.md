# 앞 공정(밀링)을 외주로 받아 내 공정에서 완성해 납품할 때는 중간중간 하나씩 가공·분해해서 치수를 확인해야 하며, 그러지 않으면 외주 공정의 오차가 그대로 내 불량이 되어 원청 책임까지 떠안는다.

👤 한 사람이 말함 · Malco JACK — 베스트정공 대표 (@MalcoJack)

밀링 공정에서 오차가 생기면 선반에서 아무리 잘 가공해도 구조적으로 불량이 날 수밖에 없습니다. 화자는 지그로 가공을 마친 뒤 분해·재조립했을 때 100 이내여야 할 치수가 105~106으로 나왔습니다. 납품 결과는 결국 내 책임이 되므로, 외주 공정을 거친 물량은 중간에 샘플을 분해해 측정하는 전수 점검 절차를 두어야 합니다. 같은 문제가 반복되면 해당 공정 설비를 들이고 직접 익혀서 내재화하는 방안도 검토할 만합니다.
