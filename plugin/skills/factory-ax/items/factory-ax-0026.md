# 무인 야간 가공을 걸 때는 인서트 팁을 모두 새것으로 바꾸고, 황삭 공구를 여러 개로 나눠 넣고, 첫 절입까지 채터를 직접 확인하고, 칩 처리 상태를 점검해야 공작물 파손과 홀더 충돌을 막을 수 있다.

👤 한 사람이 말함 · Malco JACK — 베스트정공 대표 (@MalcoJack)

아무도 없는 밤에 칩이 말리거나 공작물이 파손되면 홀더 머리로 깎게 되어 사고로 이어집니다. 시작 전에 인서트 팁을 전부 새것으로 교환하세요. 황삭 공구는 세 개를 넣는 식으로 홀더를 나눠 공구 하나에 부하가 몰리지 않게 합니다. 가공을 시작한 뒤에는 첫 절입에서 떨림이 나는지 직접 지켜보고, 문제가 없으면 절삭유를 켜고 오토파워오프를 겁니다. 오래 많이 깎으면 칩이 쌓이므로 칩 컨베이어 상태도 꼭 확인해야 합니다.
