# 제조 현장에 AI를 들이려는 소규모 제조 사업자는 센서부터 새로 다는 데 돈을 쓰지 말고, 이미 쌓여 있는 설비 알람 이력·교대 일지·작업 지시서·수기 기록부터 모아 활용할 수 있는지 먼저 확인해야 한다.

👤 출처 1곳 · 헬로티

공장에는 설비 시계열 데이터와 알람 이력 같은 정형 데이터가 있고, 교대 일지·작업 지시서·수기 관찰 기록 같은 비정형 데이터도 쌓여 있습니다. 다만 대부분 시스템마다 따로 보관돼 현장에서 바로 꺼내 쓰기 어렵습니다. 헬로티 칼럼은 높은 수율이나 고장 전조처럼 여러 변수가 함께 얽힌 패턴을 AI가 이런 과거 기록에서 찾아낼 수 있다고 봅니다. 그러니 새 센서나 장비를 사기 전에, 우리 공장에 어떤 기록이 어디에 얼마나 남아 있는지부터 목록으로 만들어 보세요. 이 내용은 기자 칼럼의 의견이며, 실제 효과를 수치로 보여 준 사례는 원문에 없습니다.
