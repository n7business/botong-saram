# PLC 전원선은 두 가닥을 서로 교차시켜 고르게 꼬고(트위스트), 최단거리로, 되도록 굵은 선으로 배선해야 노이즈와 전압 강하를 줄일 수 있다.

👤 출처 1곳 · 공학자의 자동화 실무 (@kwh-Astartech)

PLC 전원부 배선은 전원선끼리 서로 교차하도록 고르게 꼬는 트위스트를 하고, 길이가 가장 짧게 나오도록 경로를 잡습니다. 전압 강하를 줄이려면 전원선은 되도록 굵은 선을 씁니다. 도면에 트위스트 표시가 있으면 두 선을 꼰 상태로 덕트 구멍에 넣어 길이를 잰 뒤 자르면 남는 선 없이 작업할 수 있습니다.
