# 인도네시아 칼리만탄·수마트라에 생산거점이나 거래처가 있으면 원부자재 조달·완제품 운송·항공화물 일정을 산불 시즌 전에 미리 확인해야 한다.

👤 한 사람이 말함 · 산업일보

인도네시아 산불은 건기 장기화로 칼리만탄·수마트라를 중심으로 확산되며, 2026년 9월 말까지 피해 면적이 190만㏊를 넘었다. 연무와 하천 수위 저하로 공장 가동과 원료·완제품 운송이 막히고(윌마르 카하야 사례 운영 영향 5~10%), 8월 11일~10월 21일 국내선 2,775편 운항이 차질을 빚었다. 해당 지역에 거래처가 있다면 원부자재 입고일, 완제품 선적·항공화물 일정을 사전 확인하고 납기 지연 가능성을 거래처와 미리 협의한다. 직접 피해가 없는 사업장도 연무로 작업 차질과 물류 지연이 생길 수 있으므로 공급망 전체를 점검한다.
