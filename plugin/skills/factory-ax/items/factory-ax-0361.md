# 로봇·자동화 제품을 개발해 투자를 받으려는 초기 제조 사업자는 투자자에게는 활용 시장·예상 매출·사업 모델을, 실제 도입을 검토하는 고객에게는 외국산 제품과의 기술 차이·가격 경쟁력·현장 활용 가능성을 따로 준비해 설명해야 한다.

👤 출처 1곳 · 헬로티
