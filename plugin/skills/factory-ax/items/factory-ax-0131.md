# 협동로봇을 들일 때는 '협동로봇이라 안전하다'고 여기지 말고, 로봇과 주변 설비, 작업 환경을 묶은 로봇 시스템 전체를 놓고 위험성 평가를 해야 한다.

👤 한 사람이 말함 · 산업일보

개정된 로봇 안전 표준 ISO 10218은 '협동 로봇'이라는 말 대신 '협동 적용(Collaborative Application)' 개념을 강조합니다. 로봇 기종만 보고 안전하다고 판단하지 말고 로봇, 그리퍼·지그 같은 주변 설비, 작업자 동선까지 포함한 셀 전체를 평가하라는 취지입니다. 협동로봇이라는 이름 때문에 별도 평가 없이 써도 된다고 오해하는 경우가 늘어나 표준의 용어가 바뀌었습니다. 공급사나 SI 업체에 견적을 받을 때 로봇 셀 전체에 대한 위험성 평가를 해 주는지, 결과 자료를 넘겨주는지 확인하세요.
