# 제어반 전선은 미리 길이를 재서 자르지 말고 한쪽 끝을 종착점에 먼저 체결한 뒤 단자대에 맞춰 자르면 길이가 정확히 맞아 선 낭비가 없고 작업도 빨라진다.
