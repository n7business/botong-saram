# 물류·출하 공정 자동화를 계획하는 사업자는 완전 자동화를 전제로 인력 계획을 세우지 말아야 한다. 자동화가 많이 진전된 물류센터에서도 포장·상하차·검수는 여전히 수작업에 기대는 경우가 많기 때문이다.

👤 출처 1곳 · 수치 근거 · 헬로티

국내 주요 이커머스 기업 가운데에는 자동화를 집중 적용한 일부 센터만 자동화율이 높고, 여러 센터를 합친 평균 자동화율은 약 30% 수준인 사례도 있다고 합니다. 작업 대상의 크기와 형태가 일정하지 않거나 공정 조건이 자주 바뀌는 곳은 기존 자동화 설비로 대응하기 어렵습니다. 그래서 자동화 효과를 계산할 때 포장·상하차·검수에는 사람이 남는다고 보고 인력과 비용을 잡는 편이 현실적입니다.
