# 도면 검토나 불량 검출에 AI를 들이는 제조 사업자는 도입하자마자 정확도가 나온다고 기대하지 말고, 공정 기록과 불량품 데이터를 몇 달에 걸쳐 정리·통합하는 기간과 인력을 계획에 넣어야 한다.
