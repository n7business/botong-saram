# AI 로봇(피지컬 AI) 솔루션을 검토하는 제조 사업자는 시연에서 작업을 한 번 성공한 것만 보고 결정하지 말아야 하며, 작업이 실패했을 때 로봇이 이를 감지하고 복구하는지와 AI 모델을 바꾼 뒤 다시 검증할 수 있는지를 공급사에 확인해야 한다.

👤 출처 1곳 · 산업일보

로봇이 시연에서 작업을 한 번 성공하는 것과 생산라인에서 같은 작업을 안정적으로 반복하는 것은 다른 문제입니다. 뉴로메카 박종훈 대표는 현장 적용 기준으로 작업 성공률, 소요 시간, 실패 감지·복구 능력, AI 모델 변경 후 재검증 가능성을 꼽았습니다. 범용 AI 모델은 학습에 데이터가 많이 필요하고, 작업이 실패했을 때 원인을 찾기 어렵다는 한계도 있습니다. 그러니 공급사에는 실패가 났을 때 로봇이 작업을 멈추는지, 다시 시도하는지, 경로를 고치는지 시연해 달라고 요청하세요. 모델을 업데이트한 뒤 우리 라인에서 성능을 다시 검증하는 절차와 비용도 함께 확인해야 합니다. 이 기준은 로봇 공급사 대표 한 사람이 포럼에서 밝힌 의견입니다.
