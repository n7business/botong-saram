# 화낙(FANUC) 컨트롤러 장비에서 프로빙 데이터를 자동으로 입력해 쓰려는 가공업체는 장비를 처음 주문할 때 장비 제조사에 미리 요청해야 하며, 그래야 레니쇼가 화낙용으로 만든 GUI 소프트웨어가 기본으로 들어간다.

👤 출처 1곳 · Malco JACK — 베스트정공 대표 (@MalcoJack)

프로빙 데이터를 화낙 컨트롤러와 연동해 자동 입력하려면 연동 소프트웨어가 필요합니다. 공급사 설명으로는 장비를 처음 주문할 때 장비 제조사에 말하면 화낙 맞춤 GUI(Guided User Interface) 소프트웨어가 기본으로 들어가고, 컨트롤 패널에 GUI 버튼도 따로 생깁니다. 출고 뒤에 달고 싶을 때도 요청하면 최대한 맞춰 준다고 했지만, 처음 주문할 때 넣는 편이 확실합니다. 추가 비용이 드는지는 장비 제조사 견적에서 확인해야 합니다.
