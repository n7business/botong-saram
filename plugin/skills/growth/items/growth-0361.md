# AI 모델 결과가 모자랄 때 바로 가장 비싼 모델로 바꾸지 말고, 평소에는 한 단계 아래 모델(클로드는 오퍼스 5.5)을 노력 '중간'으로 쓰다가 AI가 스스로 결과를 확인할 방법 → 노력 설정 → 모델 순서로 한 단계씩 올려야 사용 한도와 비용을 아낄 수 있다.

👤 출처 1곳 · EO 플래닛

앤트로픽은 최상위 모델 페이블 5.2를 내놓으면서도 대부분의 작업은 오퍼스 5.5로 시작하라고 안내합니다. 결과가 모자라면 먼저 '합계가 표와 맞는지 스스로 확인하고 다르면 고쳐서 다시 보여 줘'처럼 AI가 직접 확인할 방법을 줍니다. 그래도 모자라면 노력(얼마나 깊이 생각할지) 설정을 한 단계 올리고, 마지막에만 모델을 바꿉니다. 노력을 '높음'으로 두고 같은 일을 여러 갈래로 돌렸다가 30분 만에 5시간 한도를 다 썼다는 사용자 글도 있습니다. 모델을 바꾸면 노력 설정이 중간으로 돌아간다는 글도 있으니, 바꿀 때마다 다시 확인하세요.
