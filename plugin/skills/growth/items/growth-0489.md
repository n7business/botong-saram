# 개발 인력이 없는 사업자는 결제 화면을 직접 만들지 말고 PG사가 미리 만들어 둔 결제위젯이나 카페24·쇼피파이의 공식 연동 앱을 쓰는 편이 부담이 적으며, 결제 화면을 직접 짜는 API 연동은 개발하고 유지보수할 사람이 있을 때만 고르는 것이 좋다.

👤 출처 1곳 · 토스페이먼츠피드

결제위젯은 미리 만들어진 결제 화면을 가져다 쓰는 방식이라, 결제 UI를 처음부터 개발할 필요가 없고 나중에 결제수단을 바꾸기도 쉽습니다. 카페24·쇼피파이 같은 쇼핑몰 솔루션을 쓴다면 그 플랫폼과 PG사가 공식으로 연동되는지부터 확인하세요. 플랫폼과 PG사 조합에 따라 쓸 수 있는 결제수단과 기능이 다릅니다. API 연동은 화면과 결제 흐름을 마음대로 설계할 수 있지만, 직접 개발하고 오류를 고칠 사람이 계속 있어야 합니다. 어떤 방식이든 실제 결제를 받기 전에 PG사가 주는 테스트 환경에서 결제와 취소를 직접 점검해 보세요.
