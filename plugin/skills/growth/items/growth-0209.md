# 경쟁 매장과 같은 메뉴를 판다면 메뉴 이름에 실제 재료와 공정의 특징을 넣는 작은 차별화부터 시도해 손님의 궁금증을 만들어 볼 만하다.

👤 한 사람이 말함 · 장사 권프로 (@권프로)

거창한 변경부터 하지 말고 메뉴 이름 하나, 서비스 포인트 하나, 우리 가게만의 포인트 하나를 바꾸는 데서 시작한다. 권프로의 예시에서는 모두가 파는 '삼겹살 수육'을 한방 재료와 조리 시간을 앞세운 '101시간 한방 삼겹살 수육'으로 바꾸자 손님이 보통 수육과 다르다고 느끼게 된다. 이 사례의 A·B 사장 비교와 '1~2년 뒤 격차'는 화자의 설명용 전망이며 실제 매출 데이터가 아니다. 이름에 넣는 재료와 시간은 실제 조리 내용과 같아야 한다.
