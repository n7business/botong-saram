# AI로 홈페이지나 상세페이지를 만들 때는 방법을 먼저 공부하기보다 기존 홈페이지(없으면 마음에 드는 레퍼런스 사이트)를 주고 초안을 받은 뒤, 초안이 영 별로면 다른 레퍼런스로 처음부터 다시 만들게 하고 괜찮으면 세부를 하나씩 고쳐 나가 볼 만하다.

👤 출처 1곳 · 무빙워터 (@무빙워터)

기존 홈페이지가 있으면 '기존 홈페이지를 참조해서 새 상세 페이지를 만들어 줘'라고 요청합니다. 그러면 AI가 무엇을 파는지 파악해 구성을 제안합니다. 홈페이지가 없으면 마음에 드는 사이트를 주고 비슷하게 만들어 달라고 해서 초안을 받습니다. 초안이 완전히 별로면 조금씩 고치지 말고 다른 레퍼런스를 주며 완전히 다르게 만들게 하고, 괜찮은 초안이 나왔을 때부터 세부를 하나씩 고칩니다. 한 운영자는 이렇게 수정을 거듭해 완성까지 약 10일이 걸렸다고 전합니다. 작업 중에 '지금까지 했던 요청을 쭉 써 줘'라고 하면 요청 이력도 정리받을 수 있습니다.
