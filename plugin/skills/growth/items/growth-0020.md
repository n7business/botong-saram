# 영문과 숫자가 섞인 제품 모델명을 AI 전화 상담이 알아듣게 하려면 모델 목록과 각 모델의 한글 발음을 규칙에 적어 두고, 비슷한 이름은 임의로 정하지 말고 고객에게 되묻도록 지시한다.

👤 한 사람이 말함 · 채널톡 블로그

전화 AI는 '프라임'처럼 줄여 말한 모델명을 멋대로 특정 제품으로 확정하면 잘못된 안내로 이어진다. 제품명이 영문·숫자 조합이라면 전체 모델 목록과 각 모델을 한글로 읽었을 때의 발음(예: 'V2'를 '브이투')을 규칙에 정리해 인식률을 높인다. 여기에 비슷한 모델명(프라임/프라임S)을 들으면 어느 쪽인지 고객이 직접 확인할 때까지 기다렸다가 안내를 이어가라는 규칙을 추가한다. 모델이 여러 개인 소형가전·디바이스 판매자는 지식보다 이 규칙을 먼저 손보는 편이 효과가 크다.
