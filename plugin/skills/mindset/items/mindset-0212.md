# AI 시대의 사업 영역을 고를 때는 'AI가 못하는 일'을 찾지 말고 'AI가 더 잘해도 사람들이 여전히 인간을 고르는 영역'이 무엇인지를 물어야 한다는 것이 캡선생 김용석의 판단 기준이다.

👤 출처 1곳 · 캡선생 김용석 (@kap_writing)

캡선생 김용석은 'AI가 절대 못하는 것은?'이라는 질문을 'AI가 할 수 있고 인간보다 잘하는데도 사람들이 계속 인간을 선택하는 영역은?'으로 바꿔야 답이 보인다고 말합니다. 예로 드는 것이 바둑입니다. AI가 이미 인간보다 바둑을 잘 두지만, 사람들은 인간이 고민하고 실수하고 극복하는 과정을 보려고 여전히 인간의 경기를 봅니다. AI가 무엇을 못하는지가 아니라 사람들이 왜 인간을 선택하는지를 기준으로 내 서비스의 자리를 찾아야 한다는 관점입니다.
