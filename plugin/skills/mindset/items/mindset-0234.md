# 메뉴 실력이 부족하면 잘한다는 카페 메뉴를 직접 재현하면서 일주일에 하나씩 신메뉴를 낸다.

👤 출처 1곳 · 사군카페인 (@sa_caffeine)

화자는 처음에 백만 원 넘게 주고 레시피를 받았습니다. 그런데 대부분 파우더에 우유를 넣는 수준이라 매출이 나지 않았고, 맛없는 카페라는 소문까지 났습니다. 그 뒤로 맛있다는 카페 메뉴를 직접 가서 똑같이 만들어 보기를 반복했습니다. 그때는 일주일에 하나씩 신메뉴를 냈습니다. 레시피를 돈 주고 사는 것만으로는 경쟁력이 되지 않습니다. 직접 만들고 고칠 수 있을 때까지 연습하세요.
