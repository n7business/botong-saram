# 아침에 혼자 출근해 제빙기·냉장고·팬 소리를 들어 보고 진동이나 끼익 소리가 평소와 다르면 바로 기사를 불러야 설비를 통째로 바꾸는 일을 막는다는 것이 장사맛집 오팀장 영상에 출연한 사장의 습관이다.

👤 출처 1곳 · 장사맛집 오팀장 (@장사맛집오팀장)

아침에 가게에 가면 제빙기, 냉장고, 팬이 돌아가는 소리처럼 원래 들려야 할 소리가 있습니다. 냉장고 진동이 드드득 세지거나 끼익 소리가 몇 초씩 나면 바로 기사를 불러 고칩니다. 가게에 자주 가지 않으면 이런 신호를 놓쳐서, 10~20% 고장 났을 때 고칠 수 있던 설비를 80%까지 망가뜨려 통째로 바꾸게 됩니다. 출연한 사장은 직원이 이런 것을 챙기는 모습은 본 적이 없다며, 조용한 아침에 사장이 직접 확인해야 한다고 말합니다.
