# 장사왕 임사부는 자기가 아는 방식이 지금도 통하는지 확인하려고 한 해에 해외에 17번 나가고 국내외 식당 300곳 이상을 벤치마킹할 만큼 밖에서 공부하는 습관을 지킨다.

👤 한 사람이 말함 · 장사왕 임사부 (@장사왕임사부)

임사부는 공부를 멈추면 자기 경험이 기준이 되어 고객의 기준과 멀어진다고 봅니다. 그래서 국내외 식당을 계속 다니며 자기 방식이 여전히 맞는지 확인합니다. 다만 모든 사장이 해외에 나갈 필요는 없고, 동네에서 손님이 꾸준히 오는 가게부터 가 보면 된다고 말합니다. 중요한 것은 다녀온 횟수가 아니라 무엇을 보고 내 가게에서 무엇을 바꿨느냐입니다. 예를 들어 메뉴판 순서를 바꾸거나, 반찬 준비 동선을 줄이거나, 손님이 자주 묻는 정보를 입구에 안내하는 식입니다.
