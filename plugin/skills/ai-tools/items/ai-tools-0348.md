# 다룰 줄 모르는 전문 프로그램도 MCP로 AI에 연결하고 원하는 작업을 설명하면, 사용법을 깊이 배우지 않아도 에이전트에게 작업을 맡길 수 있다.

👤 한 사람이 말함 · 조코딩 JoCoding

3D 전문가가 아니면 블렌더를 다루기 어렵습니다. 화자는 AI 모델에 블렌더 MCP를 연결하고 원하는 작업을 설명하기만 하면, 처음 보는 툴이라도 에이전트가 알아서 쓴다고 말합니다. MCP는 프로그램을 AI에 꽂는 표준 연결선이며, CLI나 서비스가 공식으로 열어 둔 API로도 도구를 연결할 수 있습니다. 사람은 무엇을 만들지 정하고 결과를 검토하면 됩니다. 화자의 사용 경험에 근거한 설명이고 결과 품질을 수치로 제시하지는 않았습니다.
