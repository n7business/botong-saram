# 클로드 코드의 Bash 권한 창은 내 요청과 관련 있는지, 폴더 밖을 건드리는지, 삭제·설치·업로드가 있는지 보고 승인해야, 되돌리기 어려운 명령을 무심코 허락하는 일을 막을 수 있다.

👤 한 사람이 말함 · 코드깎는노인

Bash 명령은 파일 수정보다 범위가 넓어 폴더 밖 파일 삭제·이동, 프로그램 설치, 인터넷 전송까지 할 수 있고 되돌리기 어렵습니다. 화자는 읽지 않고 Enter를 누르다가 프로젝트 밖으로 파일을 복사하는 명령을 승인한 적이 있습니다. 맨 위 설명이 내 요청과 관련 있는지, 내 폴더 밖을 건드리는지, 삭제·설치·업로드 같은 말이 있는지 세 가지를 봅니다. 모르겠으면 No로 거절하고 이 명령이 뭘 하는지 쉬운 말로 먼저 설명해 달라고 한 뒤 진행시킵니다.
