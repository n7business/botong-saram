# SNS 자동 게시를 연결할 때는 시험 게시만 믿지 말고 실제 계정에 시험 글을 올려 봐야, 본문이 잘못 찍히는 문제까지 잡을 수 있다.

한 사례에서 시험 게시는 계정과 게시 준비만 확인하고 글 내용은 보지 않았습니다. 그래서 실제 스레드 시험 글을 올린 뒤에야 그림 대신 원고의 그림 표시 문법이 글자 그대로 찍힌 문제를 발견했습니다. 시험 글을 올린 뒤에는 미리보기와 실제 글이 같은지 확인합니다. 인스타그램 글은 이 사례에서 API로 지울 수 없어 브라우저에서 지웠으므로, 시험 글을 지울 방법도 미리 정해 둡니다.
