# 에이전트 결과가 부족할 때 사고 수준(생각 깊이)을 최대로 올리면 결과는 좋아질 수 있지만 시행착오와 반복이 늘어 시간과 토큰 크레딧이 크게 늘어나므로, 같은 일을 반복할 거라면 사고 수준만 올리지 말고 도구와 작업 요령을 갖춰 줘야 한다.

👤 한 사람이 말함 · 일잘러 장피엠

사고 수준은 AI가 얼마나 오래 생각하고 토큰을 얼마나 쓸지 정하는 값으로, 올리면 더 많은 방법을 시도하며 작업을 여러 번 반복합니다. 실험에서는 같은 모델(Opus 5.5)의 사고 수준만 최대로 올리자 결과가 훨씬 좋아졌지만, 시행착오가 많아 거의 2시간이 걸리고 토큰 크레딧도 그만큼 많이 썼습니다. 한 번만 할 일이면 사고 수준을 올리는 것도 방법이지만, 반복할 일이라면 적절한 도구와 작업 요령 문서를 미리 주는 편이 더 싸고 빠릅니다.
