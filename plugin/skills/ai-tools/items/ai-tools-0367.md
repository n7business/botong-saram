# 데이터 삭제 승인이나 로그의 개인정보 가림 같은 안전 규칙은 관련 파일을 작업할 때 로드되는 조건부 규칙으로 걸어 두어야, 해당 작업에서 그 규칙을 클로드에게 빠짐없이 전달할 수 있다.

👤 한 사람이 말함 · 짐코딩 (@gymcoding)

Trigger.dev의 database-safety 규칙은 DB 관련 파일을 건드릴 때만 로드되며 '데이터 삭제는 반드시 승인 후 진행' 같은 내용을 담고 있습니다. CockroachDB는 모든 Go 파일에 규칙을 적용해, 에러 메시지나 로그에서 개인정보가 될 수 있는 항목을 가린 상태로 출력하게 합니다. 고객 정보를 다루는 도구라면 같은 방식으로 관련 파일에 안전 규칙을 걸 수 있습니다. 영상은 이를 원천 차단이라고 표현하지만, 규칙은 지시이므로 실제 출력은 따로 확인해야 합니다.
