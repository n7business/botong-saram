# 클로드는 이미지를 직접 만들지 못하므로 클로드 코드로 이미지 작업을 자동화하려면, GPT 유료 구독자는 코덱스 CLI를 연결하고 무료로 시작하려면 안티그래비티를 연결해 기획은 클로드가, 생성은 연결한 도구가 맡게 해야 한다.

👤 한 사람이 말함 · 레인 | AI 바이브코딩 (@Vibe_RaiN)

앤트로픽에는 아직 이미지 생성 모델이 없어서 클로드는 SVG·HTML로 간단한 도형 정도만 만들 수 있습니다. 클로드 코드에 '코덱스 CLI 연결해서 이미지 작업할 거야'처럼 말해 외부 생성 도구를 연결하면, 그동안 쌓인 작업 맥락과 메모리를 그대로 둔 채 이미지만 뽑아낼 수 있습니다. 코덱스 CLI를 쓰려면 GPT 유료 플랜이 있어야 합니다. 플랜이 없다면 일정량을 무료로 쓸 수 있는 구글 안티그래비티를 쓰면 되는데, 구글 계정이 있어야 하고 설정은 클로드 코드로 직접 해야 합니다. 이 방식은 앱이나 브라우저를 열지 않고 터미널 안에서 돌아가므로 자동화 루프에 넣기 좋습니다.
