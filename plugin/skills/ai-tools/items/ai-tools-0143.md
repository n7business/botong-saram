# AI로 웹페이지에 애니메이션을 넣을 때는 '모션 감소 설정(reduced motion)을 따르게 해줘'를 꼭 붙이고, 커스텀 커서처럼 마우스 전용 효과는 모바일에서 끄게 지시한다.

👤 한 사람이 말함 · 코드깎는노인

기기에서 움직임 줄이기를 설정해 둔 사용자도 있으므로, 애니메이션 요청 끝에 모션 감소 설정을 따르라는 문장을 붙입니다. 컨페티처럼 큰 효과는 '모션 감소 사용자에게는 생략'이라고 명시합니다. 터치 화면에는 커서가 없으니 커스텀 커서는 데스크톱에서만 켜고, 가로 스크롤 섹션도 모바일에서는 세로 목록으로 바꾸게 함께 적습니다.
