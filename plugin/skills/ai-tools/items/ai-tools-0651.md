# AI가 대신 클릭하는 AI 브라우저는 크롬과 나눠 써야 한다. 여러 사이트를 돌며 가격·자료를 표로 정리하거나 같은 클릭을 반복하는 일만 맡기고, 은행·증권·관공서처럼 보안 프로그램이 붙는 사이트와 결제·개인정보 입력은 크롬에서 직접 해야 한다.

👤 출처 1곳 · 윤자동 | AI자동화로 세상을 돕는중 (@yun_ja_dong)

어사이드 같은 AI 브라우저는 사이트를 열고 클릭하고 입력하는 일까지 대신합니다. 크롬은 그대로 두고 하나 더 깔아 나눠 쓰면 편합니다. AI 브라우저에는 여러 사이트에서 가격이나 자료를 모아 표로 정리하는 일, 같은 클릭과 입력을 되풀이하는 일을 맡기세요. 보안 프로그램이 붙는 은행·증권·관공서 사이트와, 눈으로 확인해야 하는 결제·개인정보 입력은 크롬에서 직접 하는 편이 맞습니다. 처음에는 '네이버에서 ○○ 검색해서 상위 3개를 표로 정리해 줘' 같은 작은 심부름부터 맡겨 보세요.
