# 업무를 AI 에이전트에 맡기더라도 사람이 화면에서 직접 처리할 수 있는 길은 남겨 두어야, 모델 장애가 나거나 토큰 한도를 넘겼을 때 업무가 멈추지 않는다.

👤 한 사람이 말함 · 요즘IT

AI 에이전트로 일하는 방식이 익숙해지면 기존 관리 화면이나 수작업 절차를 없애고 싶어집니다. 하지만 에이전트 모델에 장애가 생기거나 사용량 한도를 넘기면 그날 업무가 통째로 멈출 수 있습니다. 주문 처리, 가격 수정처럼 꼭 해야 하는 일은 에이전트 없이도 사람이 직접 처리할 수 있는 화면과 절차를 남겨 두세요. 사람이 결과를 확인하거나 여럿이 같은 화면을 보며 논의할 때도 이 화면이 필요합니다.
