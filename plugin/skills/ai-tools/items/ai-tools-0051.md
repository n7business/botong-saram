# 오픈 웨이트 모델을 귀중한 데이터가 있는 인터넷 연결 환경에서 돌릴 때는 출처·학습 환경·보안 검증을 거치고, 검증이 어려우면 인터넷을 끊은 환경에서만 쓴다.
