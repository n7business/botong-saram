# AI로 홈페이지용 사진·영상·음악을 만들 때는 인물 얼굴에 본인 또는 허락받은 사람의 사진만 쓰고, 음악은 실제 노래 대신 AI로 새로 만든 곡을 쓰라고 메시지에 적어야 저작권·초상권 문제를 피할 수 있다.

👤 출처 1곳 · 코드깎는노인

화자는 강사 얼굴에 반드시 본인 사진을 썼고, 다른 사람의 얼굴을 허락 없이 올리면 안 된다고 강조했습니다. 음악은 저작권 문제가 없도록 실제 노래 대신 Higgsfield로 새로 만든 비트를 쓰게 했습니다. 모든 사진과 영상에서 얼굴·안경·의상이 똑같이 유지되도록 하라는 조건도 함께 적었습니다. 직원 얼굴을 쓸 때는 사전 동의를 받아 두는 것이 안전합니다.
