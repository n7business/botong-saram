# AI에게 문서 정리 위키를 만들게 했다면 위키 분량이 원본 문서와 비슷하거나 더 커지지 않았는지 확인해야 한다. 그렇게 커진 위키는 아무것도 압축하지 못해 원본을 뒤지는 것과 다를 바 없기 때문이다.

🏛 공식 발표 · Anthropic Engineering 블로그

Anthropic 실험의 한 과제에서 AI가 만든 위키가 원본 문서보다 커졌습니다. 내용을 지나치게 자세히 옮기다 보니 요약·정리 효과가 사라진 것입니다. 위키를 만들게 한 뒤에는 전체 분량을 원본과 비교해 보세요. 너무 크다면 '중복을 합치고 핵심만 남기고 세부 내용은 원본 링크로 대신하라'고 다시 정리를 시켜야 합니다.
