# AI와 대화하다가 작업 방식을 바꿀 때는 새 방식만 말하지 말고, 버릴 예전 방식과 새로 쓸 방식을 둘 다 적어 처음부터 다시 쓰게 해야 한다. 대화가 길어지면 AI가 앞에서 정한 방식을 계속 섞어 쓰기 때문이다.

👤 출처 1곳 · 윤자동 | AI자동화로 세상을 돕는중 (@yun_ja_dong)

'앞에서 한 (예전 방식)은 전부 버리고 (새 방식)만 써서 처음부터 전체를 새로 써 줘. 쓰기 전에 예전 방식이 섞이지 않았는지 스스로 확인해 줘'처럼 보내세요. 답이 오면 예전 방식이 섞였는지 한 번 더 물어보세요. 그래도 같은 일이 반복되면 새 대화를 열고, 정해 둔 규칙과 지금까지 만든 결과물을 첫 메시지에 붙여 넣으세요. 클로드를 쓴다면 프로젝트 기능의 지침 칸에 규칙을 적어 두면 그 프로젝트 안의 모든 대화에 적용됩니다.
