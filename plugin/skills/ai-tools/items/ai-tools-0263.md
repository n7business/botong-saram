# 코덱스의 완료 보고에 문법 검사 통과만 있으면 실제 동작은 확인되지 않은 것이므로, 확인 못 한 부분을 직접 열어 눌러 본 뒤 넘어가야 한다.

👤 한 사람이 말함 · 코드깎는노인

보고는 확인한 것과 못 한 것을 나눠 읽어야 합니다. 마지막 줄에 '문법 검사 통과'만 있다면 브라우저에서 눌러 보는 확인은 아직 안 한 것입니다. 문법이 맞아도 버튼이 제대로 동작한다는 보장은 없으니, 확인 못 한 부분은 고장 나 있을 수 있다고 보세요. 그냥 넘어가면 나중에 어디서 잘못됐는지 찾기가 훨씬 어려워집니다. 부탁할 때 다 되면 무엇으로 확인할지까지 적어 두면 결과가 내 생각에 더 가까워집니다.
