# AI 에이전트에게 유료 음성 합성(TTS)으로 내레이션을 맡길 때는 대본을 먼저 확인하고 확정한 뒤에 녹음을 허락해야 하는데, 대본이 바뀔 때마다 다시 녹음하면 크레딧이 낭비되기 때문이다.

👤 한 사람이 말함 · 코드깎는노인

TTS 서비스는 녹음할 때마다 크레딧이 빠지므로 대본이 덜 다듬어진 상태에서 음성을 만들면 고칠 때마다 비용이 다시 든다. 에이전트가 마음대로 녹음을 시작하지 않게 하고, 사람이 대본을 확인한 뒤 '녹음해'라고 명시적으로 지시하는 순서를 지킨다. 에이전트는 소리를 들을 수 없으므로 녹음 뒤 어색한 발음이나 타이밍은 사람이 직접 듣고 알려 줘야 한다. 목소리를 복제해 쓴다면 본인 목소리이거나 허락받은 목소리여야 한다.
