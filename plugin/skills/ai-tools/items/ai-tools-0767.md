# 핀터레스트에 올린 이미지는 계정 전체 노출 수로 평가하지 말고, 핀마다 저장 수와 외부 링크 클릭 수를 따로 봐야 한다. 나중에 보려고 저장한 사람과 링크를 눌러 내 페이지로 넘어온 사람은 서로 다른 행동을 한 것이기 때문이다.
