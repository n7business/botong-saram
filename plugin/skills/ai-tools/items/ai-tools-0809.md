# AI 영상 프롬프트에 '글에 없는 요소를 보태지 말라'고 적어도 AI는 빈 곳을 스스로 채운다. 영상에 꼭 나와야 할 장소·인물·사물·행동은 글에 빠짐없이 적어야 한다.

화자 팀은 Seedance 2.5로 글에서 영상을 만들면서 '글에 없는 요소를 보태지 않는다'를 고정 규칙으로 넣었습니다. 그래도 AI는 빈 곳을 채웠습니다. 글에 적지 않은 것은 다음 영상에서 사라지고, 적은 것은 AI가 자기 방식으로 채웠습니다. 그래서 안개 낀 호숫가 저택에서 시작한 영상이 아홉 번 만에 수정으로 된 세계가 됐습니다. 광고처럼 원하는 결과가 정해져 있다면 금지 문구에 기대지 마세요. 필요한 요소를 모두 글로 적고 결과물을 직접 확인해야 합니다.
