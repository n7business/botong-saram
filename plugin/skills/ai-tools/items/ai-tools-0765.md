# 같은 AI 인물로 이미지 시리즈를 만들 때는 레퍼런스 두 장의 역할을 나눠야 한다. 첫 번째 이미지에는 인물 기준 이미지를 넣고, 두 번째 이미지에는 원하는 장면을 넣되 포즈·옷·빛만 참고하라고 지정해야 두 사람의 특징이 섞이지 않는다.

👤 출처 1곳 · 지피터스 GPTers

레퍼런스 이미지를 두 장 넣을 때는 첫 번째에 얼굴과 체형이 잘 보이는 캐릭터 기준 이미지를 넣습니다. 두 번째에는 원하는 장면 이미지를 넣고 '포즈와 조명만 참고하라'고 프롬프트에 직접 적습니다. 첫 번째 이미지에서 지킬 특징도 '코와 입술 모양, 턱선, 어깨와 다리의 비율'처럼 구체적으로 적습니다. 역할을 나누지 않으면 장면 이미지 속 사람의 얼굴이 섞여, 배경이 마음에 들어도 같은 시리즈로 쓰기 어렵습니다.
