# Claude Code 작업의 80% 이상은 데스크톱 앱으로 충분하지만, 만들어진 결과 파일을 바로 확인하고 고쳐야 하면 VS Code 확장(Claude for VS Code)에서 쓴다.

👤 한 사람이 말함 · 레인 | AI 바이브코딩 (@Vibe_RaiN)

데스크톱 앱의 Code 탭에서 '새로 만들기'를 누르고 디렉토리를 지정하면 허용한 폴더에 접근하고, 변경 사항과 컨텍스트 사용량도 볼 수 있습니다. 다만 결과 파일을 앱 안에서 바로 고칠 수는 없습니다. 파일을 고치면서 작업하려면 VS Code 확장 탭에서 Claude for VS Code를 설치하고, 폴더를 연 뒤 새 터미널에서 Claude 아이콘을 누릅니다. 파이썬 스크립트 실행처럼 터미널에서만 되는 작업도 가끔 있지만, 어디서 쓰든 모델은 같습니다.
