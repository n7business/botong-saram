# 비개발자가 바이브 코딩으로 첫 서비스를 만들 때는 거창한 아이디어 대신 내가(또는 가까운 사람이) 당장 쓸 작은 서비스를 골라야 완성까지 가고 열정이 꺼지지 않는다.

👤 한 사람이 말함 · 요즘IT

첫 프로덕트는 퇴근 후 짬으로 만들 수 있을 만큼 볼륨이 작고, 실제로 쓸 사람이 정해진 것으로 고른다. 바이브 코딩에서 가장 해로운 것은 중간에 열정이 식는 것이고, 실제 서비스로 띄워야 지속성이 생긴다. 기획자인 필자는 직원 휴가 일정 공유 캘린더를 골라 Render·Supabase·카카오 로그인으로 설계·프로토타입·QA·런칭까지 약 1주일 만에 끝냈다. 단, 카카오톡 로그인 연동만 3일이 걸렸으므로 외부 로그인 연동은 일정에 따로 잡아 둔다.
