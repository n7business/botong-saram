# AI 코딩 세션을 여러 개 동시에 돌릴 때는 세션 수를 무작정 늘리지 말고, 어떤 상황에 세션을 열고 결정 사항을 어디에 기록하며 결과를 어떤 순서로 합칠지 운영 규칙부터 정해야 한다. 규칙 없이 세션만 늘리면 사람이 결정하고 검토할 일이 쌓여 오히려 느려지기 때문이다.

👤 출처 1곳 · 요즘IT

AI 세션을 여러 개 띄우면 혼자서도 팀 몫을 할 것처럼 보입니다. 하지만 세션이 많아지면 코드 충돌 해결, 합치는 순서 결정, 이전 결정 재확인처럼 사람이 판단해야 할 일이 한꺼번에 몰립니다. 화자는 세션이 8개를 넘자 진행 상황을 파악하는 데 더 많은 시간을 쓰게 됐고, 머리가 멍해질 만큼 인지 부하가 커졌다고 말합니다. 그래서 세션을 더 늘리지 않고 운영 규칙부터 만들었습니다. 규칙을 적용한 뒤 주간 PR 병합은 29건에서 211건으로 늘었습니다. 여러 AI 작업을 동시에 맡기려면 사람의 판단이 병목이 된다는 점을 먼저 생각해야 합니다.
