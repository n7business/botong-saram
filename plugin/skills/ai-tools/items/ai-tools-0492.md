# 클로드 코드에서 API 키로 페이블 5.2를 쓴다면 출력 토큰이 입력보다 5배 비싸고 캐시에서 다시 읽는 입력은 40분의 1 값이므로, 긴 자료는 매번 새로 넣지 말고 같은 맥락을 이어 쓰게 하고 결과물은 필요한 만큼만 길게 쓰게 해야 비용을 줄일 수 있다.
