# 복잡한 업무용 에이전트는 한 번에 만들지 말고 작은 단위의 하위 에이전트를 먼저 잘 만든 뒤 조합해야 비교적 잘 처리된다.

👤 한 사람이 말함 · 테디노트 TeddyNote

복잡한 작업을 작은 단위로 쪼개 재료가 되는 하위 에이전트부터 만듭니다. 그다음 필요에 따라 이들을 조합해 상위 에이전트를 만듭니다. 서브 에이전트의 결과는 메인 에이전트가 받아 자기 지침의 형식대로 다시 정리하므로, 메인 에이전트에 다른 답변 형식을 줄 수 있습니다. 멀티 에이전트는 5분, 10분 이상 걸리기도 하므로 오래 걸리는 작업임을 감안해야 합니다.
