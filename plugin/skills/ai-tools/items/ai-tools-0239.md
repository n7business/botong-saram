# AI가 경쟁이 적다고 추천한 시장은 그대로 믿지 말고 해당 분야의 상위 서비스를 직접 확인해야, 이미 경쟁이 있는 시장에 무턱대고 들어가지 않는다.

👤 한 사람이 말함 · 지피터스 GPTers

한 제작자가 챗GPT에 앱 수가 적고 재방문율이 높은 분야를 물어 생활 서비스 쪽 답을 받았습니다. 직접 들어가 보니 교체 주기를 알려 주는 미니앱은 이미 많았습니다. 1~10위를 확인한 결과 특정 제품이나 영역만 다루는 앱이 많다는 점을 찾아, 전체 영역을 다루는 방향으로 기획을 바꿨습니다. 이 앱의 재방문 데이터는 아직 없어 차별화 효과는 검증되지 않았습니다.
