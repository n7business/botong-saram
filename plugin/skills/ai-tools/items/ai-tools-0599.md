# AI가 만든 웹페이지나 업무 화면은 시안과 똑같아 보여도 끝난 것이 아니므로, 버튼을 실제로 눌러 저장, 확인창, 등록 요청이 제대로 일어나는지 확인해야 한다.

👤 출처 1곳 · 요즘IT

AI에게 쿠폰 등록 같은 화면을 맡기면 시안과 꼭 닮은 화면이 금방 나옵니다. 그런데 저장 버튼을 눌러도 아무 일이 일어나지 않는 경우가 있습니다. 이런 문제는 화면 캡처나 코드만 봐서는 드러나지 않습니다. 그러니 겉모습만 보고 넘기지 말고, 입력하고 버튼을 누르는 실제 사용 흐름을 처음부터 끝까지 따라가 보세요. 이 확인까지 끝나야 AI로 시간을 아낀 것입니다.
