# 회의 중에 바로 보여 줘야 할 파일은 그 자리에서 에이전트에게 찾아 달라고 맡기지 말고 미리 찾아 두거나 검색 색인을 갖춰 두어야 하는데, 색인 없이 폴더를 뒤지는 에이전트는 한글 파일 하나를 찾는 데 15분이 걸리기도 했기 때문이다.

👤 한 사람이 말함 · 테디노트 TeddyNote

한 발표자는 회의 중에 에이전트에게 한글 파일을 찾아 달라고 했는데, 몇 분이 지나도 계속 찾기만 했다고 합니다. 15분 만에 파일을 찾았을 때는 이미 회의가 끝나 설명할 기회를 놓쳤다고 합니다. 색인 없이 폴더를 직접 탐색하는 방식은 파일이 많을수록 느려질 수 있습니다. 급하게 써야 할 자료는 미리 준비해 두고, 자주 찾는 문서 묶음이 있다면 검색 색인(RAG 등)을 갖추는 것을 검토하세요. 한 사람의 경험담입니다.
