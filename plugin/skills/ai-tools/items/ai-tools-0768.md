# AI로 만든 서비스나 사이트의 이름과 도메인을 정하기 전에 같은 이름을 먼저 검색해, 다른 플랫폼에 밀려 있지 않은지 확인해야 한다. 화자는 처음 정한 이름이 검색에서 이미 다른 플랫폼에 밀려 있어서 만든 뒤에 이름과 도메인을 통째로 바꿨다.

👤 출처 1곳 · 지피터스 GPTers

바이브코딩으로 서비스를 빨리 만들 수 있어도, 이름이 검색에서 다른 곳에 밀려 있으면 손님이 찾아오기 어렵습니다. 도메인을 사거나 화면에 이름을 넣기 전에 검색창에 후보 이름을 넣어 보고 같은 이름이나 비슷한 이름의 서비스가 위에 뜨는지 확인합니다. 나중에 바꾸면 도메인과 화면 전체를 다시 손봐야 합니다.
