# AI로 발표자료나 사업계획서를 만들었다면 그대로 내지 말고, AI가 남긴 '가설이며 실제 인용이 아님' 같은 한계 메모를 찾아 실제 근거로 고친 뒤 내야 한다.

👤 출처 1곳 · 윤자동 | AI자동화로 세상을 돕는중 (@yun_ja_dong)

AI로 PPT를 만들면 AI가 근거 없는 내용에 '현재 문제 정의는 가설이며 실제 인용이 아님' 같은 메모를 정직하게 남기기도 합니다. 화자가 심사한 해커톤에는 이 문구를 지우지 않은 채 발표 자료에 그대로 둔 팀도 있었습니다. 이런 메모를 읽고 실제 경험이나 자료로 바꾸면 좋은 발표가 되고, 안 읽으면 그대로 드러납니다. 정부지원사업 신청서나 투자 제안서처럼 남이 읽는 문서라면 특히 끝까지 읽어 봐야 합니다.
