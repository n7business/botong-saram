# AI가 구현을 완료했다고 하면 어떤 파일이 바뀌었는지와 실제로 작동하는지를 모두 확인해야, 예상보다 넓은 수정과 작동하지 않는 기능을 놓치지 않는다.

👤 한 사람이 말함 · 양실장의 바이브코딩대학 (@VibecodingUniversity)

AI의 완료 보고를 받으면 먼저 어떤 파일이 수정됐는지, 예상보다 많은 부분을 건드리지 않았는지 본다. 그다음 직접 실행해 요청한 기능이 화면에서 제대로 동작하는지 확인한다. 예를 들어 회의실 사용 목적 입력 기능을 요청했다면 목적을 입력해 보고 예약 목록에 제대로 보이는지 살핀다. AI가 실행했다는 말만 듣지 말고 브라우저를 직접 열어 결과를 확인한다.
