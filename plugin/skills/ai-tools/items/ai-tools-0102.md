# Claude Code는 업데이트가 매우 잦으므로 공식 문서의 세 가지 설치 방법 중 자동 업데이트되는 네이티브 설치로 깔고, 윈도우에서는 CMD 대신 PowerShell로 설치하면서 Git도 함께 설치한다.

👤 한 사람이 말함 · 짐코딩 (@gymcoding)

구글에서 '클로드 코드'를 검색해 공식 문서(code.claude.com)의 빠른 시작 메뉴를 따라 설치합니다. 세 가지 설치 방법 중 네이티브 설치를 고르면 이후 업데이트가 자동으로 적용됩니다. macOS는 터미널에, 윈도우는 CMD가 아니라 PowerShell에 설치 명령어를 붙여 넣습니다. 윈도우 사용자는 공식 문서 권장대로 Git도 설치하세요. 함께 깔리는 Git Bash로 리눅스식 명령어를 쓸 수 있어 Claude Code가 더 매끄럽게 돌아갑니다. 설치가 끝나면 'claude --version'을 입력해 버전이 나오는지 확인합니다.
