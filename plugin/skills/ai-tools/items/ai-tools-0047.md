# 워드프레스·PHP 기반 사이트(카페24 포함)를 운영하면 보안 취약점 소식이 나왔을 때 먼저 백업하고 즉시 PHP·플랫폼을 최신 버전으로 업데이트한다.

👤 한 사람이 말함 · 조코딩 JoCoding

PHP, Node.js, GitLab에서 심각한 취약점이 나왔고, 전 세계 웹사이트의 39.6%가 쓰는 워드프레스가 PHP 기반이라 영향이 크다. 구버전 PHP 서버는 주소창 입력만으로 몇 초 만에 장악돼 데이터 유출·파일 변조·비밀 탈취로 이어질 수 있다. 카페24도 PHP 기반이며 100% 방어를 보장하지 않으니 PHP 최신 버전으로 올리라고 공지했다. 순서는 백업 → 업데이트 적용이며, 업데이트 중 깨질 수 있으니 백업을 건너뛰지 않는다. 취약점 정보가 패치 전에 새어 대응 시간이 줄었으므로, 앞으로 보안 소식이 나오면 바로 업데이트할 준비를 평소에 해 둔다.
