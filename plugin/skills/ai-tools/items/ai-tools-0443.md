# 바이브코딩으로 만드는 프로젝트가 커지면 프로젝트 설명을 담은 기획서 텍스트 파일을 만들어 두고, 요청할 때마다 이번에 고칠 범위를 버튼 하나처럼 한 가지로 정해 줘야 AI가 앞서 만든 구조를 잊고 코드를 덮어쓰는 일을 줄일 수 있다.

👤 한 사람이 말함 · 지피터스 GPTers

코드가 길어질수록 AI는 방금 만든 데이터베이스 구조나 버튼 기능을 잊고 제멋대로 덮어쓰기 쉽습니다. 무엇을 만드는 프로젝트인지 적은 기획서 파일을 따로 두고 매번 함께 주세요. 그리고 '이번에는 이 버튼 하나만 고친다'처럼 수정 범위를 한정하세요. 한 번에 여러 가지를 고치게 하면 멀쩡하던 부분이 망가질 가능성이 커집니다. 비개발자 한 명의 경험담이라는 점을 감안해야 합니다.
