# 내 업무용 AI 에이전트를 만들 때는 처음부터 내 업무를 설명하며 짜지 말고, 딥리서치로 참고할 GitHub 저장소(에이전트·스킬)부터 찾아 그대로 돌려 본 뒤 내 상황에 맞게 고쳐 쓴다.

👤 한 사람이 말함 · 일잘러 장피엠

에이전트는 그대로 쓸 때보다 내 니즈·스타일에 맞게 고쳐 쓸 때 진짜 힘이 나오고, 범용 도구보다 특정 회사·개인에게 맞출수록 가치가 커진다. 그러나 백지에서 시작하지 말고 먼저 딥리서치 기능으로 참고할 만한 에이전트나 스킬이 담긴 GitHub 저장소를 찾아야 전문가가 AI를 쓰는 방식을 빨리 흡수하고 효능감을 느낄 수 있다. 화자의 PPT 에이전트는 인기 저장소 'PPT Master'를, 크롤링 에이전트는 Agent Browser와 Scrapling 두 오픈소스를 결합해 만든 것이다. 가져온 프로젝트는 꼼꼼히 검증하고 자기 노하우와 취향을 얹는다. 수정은 원하는 것을 평범한 말로 설명하면 되고, 초보라면 Plan Mode로 켜고 원하는 것을 설명한 뒤 방법을 물어보면 계획을 세워 준다.
