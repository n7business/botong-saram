# AI에게는 틀려도 사람이 되돌릴 수 있는 지점까지만 맡기고, 되돌리기 어려운 결정은 사람에게 남겨야 오류의 대가가 커지는 일을 막을 수 있다.

맡기기 전에 AI가 틀렸을 때 무엇이 망가지는지부터 확인합니다. 판례 기반 법률 AI 서비스 사례에서는 쟁점 정리는 변호사 상담에서 바로잡을 수 있어 AI에게 맡기고, 소송 여부는 끝까지 사람의 몫으로 남겼습니다. HR 담당자 사례에서도 평가 내용 정리와 급여 데이터 처리는 자동화했지만, 최종 판단과 직원과의 소통은 사람이 맡습니다. 반대로 결과가 틀려도 웃고 넘길 가벼운 일에는 AI에게 더 많이 맡겨도 됩니다.
