# AI 자동화 도구는 만들 수 있는지보다 자주 하는 일인지, 오래 걸리는지, 틀리면 위험한지, 다시 쓸 수 있는지를 먼저 따져 골라야, 쓰지 않을 도구에 드는 품을 줄일 수 있다.

👤 한 사람이 말함 · 요즘IT

자동화할 일 후보를 빈도, 1회 소요 시간, 틀렸을 때의 위험, 재사용 가능성의 네 기준에 대 봅니다. 사례의 담당자는 매달 마감 때 30분~1시간이 걸리고 하나만 놓쳐도 마감이 틀어지는 400페이지 서명 확인 작업을 가장 먼저 자동화했습니다. 반대로 1년에 한두 번 하는 작업은 만들 수 있어도 만들지 않았습니다. 그런 일은 도구를 만들고 관리하는 품이 더 클 수 있기 때문입니다. 한 사람의 경험에서 나온 기준이므로 내 업무에 맞게 조정해 쓰면 됩니다.
