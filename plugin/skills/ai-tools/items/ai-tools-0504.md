# 메신저로 AI에게 일을 시키다가 로그인처럼 사람이 직접 처리해야 하는 단계가 나오면 비밀번호나 인증번호를 AI에게 보내지 말고, 크롬 원격 데스크톱 같은 원격 화면으로 폰에서 직접 입력해야 한다.

👤 한 사람이 말함 · 윤자동 | AI자동화로 세상을 돕는중 (@yun_ja_dong)

메신저로 AI에게 일을 맡기다 보면 로그인이나 본인 인증처럼 사람이 화면에서 직접 해야 하는 일이 생깁니다. 이럴 때 비밀번호나 인증번호를 채팅으로 AI에게 보내면 안 됩니다. 집이나 사무실 컴퓨터에 크롬 원격 데스크톱 원격 액세스를 설치해 컴퓨터 이름과 PIN을 정하고, 폰에는 Chrome 원격 데스크톱 앱을 깔아 같은 구글 계정으로 로그인해 두세요. 인증이 필요할 때 폰에서 컴퓨터 화면을 열어 직접 입력하면 됩니다. 이때 컴퓨터가 꺼져 있거나 잠자기 상태면 접속이 되지 않습니다.
