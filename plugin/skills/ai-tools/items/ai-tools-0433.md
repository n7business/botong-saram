# AI에게 초안을 다 쓰게 한 뒤에는 문단끼리 잘 이어지는지 AI가 스스로 검토하고 끊기는 곳을 고치게 해야, 한 부분씩 나눠 쓴 글의 흐름이 끊기는 일을 줄일 수 있다.
