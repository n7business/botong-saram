# 클로드 코드에게 업무용 에이전트를 만들게 할 때는 계획 단계에서 'Claude 구독 안에서만 만들고 API 추가 비용은 들면 안 된다'고 직접 적어야 한다. 이 말을 하지 않으면 기본으로 유료 API 연결을 추천하는 경향이 있기 때문이다.

👤 출처 1곳 · 레인 | AI 바이브코딩 (@Vibe_RaiN)

클로드 코드 계획 모드에서 에이전트를 설계하면 AI 모델을 어떻게 연결할지 묻는 질문이 나옵니다. 이때 '기타' 항목에 'Claude 구독제 안에서 만들고 API 추가 비용은 들면 안 된다'고 적어야 합니다. 화자 사례에서는 이렇게 적자 계획서에 Claude Code CLI를 연결해 구독 안에서만 쓰고 추가 비용은 0원이라는 안이 나왔습니다. 다만 이 방식은 내 컴퓨터에서 나 혼자 쓰는 도구에만 맞습니다. 고객에게 파는 서비스라면 API 키 방식으로 만들어야 합니다.
