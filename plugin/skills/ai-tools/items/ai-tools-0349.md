# 여러 기관과 주고받을 메일과 제출 자료가 많을 때는 가진 자료를 에이전트에 넘겨 응대를 맡기면 대량의 메일·계산서·증빙 작업을 처리할 수 있지만, 최종 검토는 사람이 해야 한다.

👤 한 사람이 말함 · 조코딩 JoCoding

화자는 정부 과제 '모두의 창업' 프로젝트에 솔루션을 공급하면서 가진 자료를 모두 넘기고 이메일 응대를 에이전트에게 맡겼습니다. 에이전트는 21개 기관에서 온 메일 195통을 읽고 처리했습니다. 발신자 74명을 상대로 계산서 21건을 발행했고, 증빙 엑셀 39개와 추가 문서 10개를 만들어 각각 첨부하며 소통을 진행했습니다. 화자는 결과를 기준에 대 보는 일을 에이전트도 어느 정도 할 수 있지만 최종 검토는 사람이 해야 한다고 말합니다. 한 사람의 경험이고 오류율이나 절감 시간은 제시되지 않았습니다.
