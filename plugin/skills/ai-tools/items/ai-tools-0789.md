# 클로드 코드에서 /desktop으로 터미널 작업을 데스크톱 앱으로 넘기거나 --teleport로 웹 작업을 터미널로 가져오려면 claude.ai 구독이 있어야 한다. API 키(Console)로만 로그인했다면 이 기능은 쓸 수 없다.

🏛 공식 발표 · Claude Code 공식 문서

공식 문서는 Teleport와 /desktop 넘기기 모두 claude.ai 구독이 필요하다고 적고 있습니다. /desktop은 macOS와 x64 윈도우에서만 됩니다. 여러 기기와 화면을 오가며 일할 계획이라면 API 키 대신 Pro·Max 같은 구독 계정으로 로그인해야 합니다.
