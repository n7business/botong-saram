# AI로 화면을 자주 만든다면 매번 피그마로 그리지 말고, AI가 활용하기 좋은 디자인 시스템을 먼저 만들어 두고 그것을 바탕으로 AI가 화면을 구성하게 해야 이후 작업 속도가 빨라집니다.

👤 출처 1곳 · 요즘IT

Smooth AI는 피그마를 거의 쓰지 않고, AI가 활용하기 좋은 디자인 시스템을 만들어 그 위에서 화면을 구성하는 방식으로 바꿨습니다. 처음 기반을 만드는 데는 시간이 많이 들었습니다. 대신 이후 작업 속도를 높이는 데 도움이 됐다고 합니다. 한 번 만들고 끝낼 화면이라면 득이 적고, 화면을 계속 만들어야 할 때 시도해 볼 만합니다.
