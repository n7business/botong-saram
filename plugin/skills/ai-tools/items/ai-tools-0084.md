# 업무에 AI를 넣을 때는 기능을 많이 만들기보다 무엇을 시스템이 판단하고 무엇을 사람이 책임질지 먼저 정하고, 서류를 현재 유효한 상태 데이터로 바꿔 정상 건은 자동 처리하고 예외만 사람이 보게 설계한다.

👤 한 사람이 말함 · 양실장의 바이브코딩대학 (@VibecodingUniversity)

한솔그룹 안전보건 출입 절차 AX 해커톤에서 대상은 기능을 가장 많이 만든 팀이 아니라 업무 취지와 목적부터 고민한 팀이 받았다. 심사평의 기준은 세 가지였다. 종이 서류 중심 업무를 '지금 유효한가'를 보여 주는 상태 데이터로 바꿨는지, 문제없는 건은 자동으로 넘기고 예외만 사람이 보게 했는지, 법적 요건과 고위험 대상을 데이터로 골라냈는지다. 수상팀은 중대재해처벌법과 최근 판례(서류 유무가 아니라 실제 이행·기록 여부를 따짐)라는 도메인 지식으로 목적을 '안전'으로 정의한 뒤 기능을 붙였다. 내 업무를 AI로 바꿀 때도 먼저 가장 큰 리스크가 무엇인지 정하고, 사람이 볼 예외 조건을 명시한 뒤 나머지를 자동화한다.
