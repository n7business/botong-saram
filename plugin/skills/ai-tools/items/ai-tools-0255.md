# AI에게 앱 제작을 맡길 때 스펙과 완료 기준을 코드 작성 전에 정하고 실제 브라우저 자동 테스트까지 갖추면, 비용과 시간은 더 들어도 겉만 그럴듯한 결과물을 피할 수 있다.

👤 한 사람이 말함 · 수치 근거 · 짐코딩 (@gymcoding)

짐코딩이 소개한 앤스로픽 실험에서는 같은 클로드 모델에게 레트로 게임 메이커를 만들게 했다. 하네스 없이 시키면 20분에 9달러가 들었지만 캐릭터가 나와도 조작이 안 되는 앱이 나왔다. 구체적 스펙, 사전 완료 기준 합의, 실제 브라우저 자동 테스트를 갖추자 6시간에 200달러가 들었고 완성된 앱이 나왔다. 플레이라이트나 퍼피티어를 연결하면 AI가 브라우저를 열고 사용자처럼 클릭하며 테스트할 수 있다. 이 수치는 한 실험의 사례를 영상으로 전해 들은 것이므로 내 작업의 비용 기준으로 삼으면 안 된다.
