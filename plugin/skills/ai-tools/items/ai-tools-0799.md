# Design Mode로 내 컴퓨터에 저장된 HTML 파일을 열어 고치려면 브라우저 확장 프로그램 설정에서 '파일 URL 접근 허용'을 따로 켜야 한다.

👤 출처 1곳 · 요즘IT

AI로 만든 홈페이지 시안을 서버에 올리기 전에 내 컴퓨터에서 바로 열어 손보고 싶을 때가 있습니다. Design Mode는 일반 웹페이지에서는 설치만 하면 바로 쓸 수 있지만, 로컬 HTML 파일은 브라우저의 파일 URL 접근 권한이 따로 필요합니다. 파일을 열었는데 패널이 동작하지 않으면 확장 프로그램 관리 화면에서 이 권한부터 켜 보세요.
