# 힉스필드 무료 체험을 시작할 때는 결제 카드를 등록해야 하고 체험이 끝나기 전에 취소하지 않으면 플러스 유료 구독이 자동으로 시작되므로, 계속 쓸 생각이 없다면 끝나기 전에 클로드에게 'cancel auto-renewal'이라고 말해 자동 갱신을 꺼야 한다.

👤 출처 1곳 · 코드깎는노인

화자에 따르면 새 계정은 플러스 요금제를 3일 동안 0달러로 쓸 수 있고, 클로드에서 쓸 크레딧 100개가 들어 있습니다. 예전에 가입한 계정은 체험 대상이 아닙니다. 체험이 끝날 때까지 취소하지 않으면 가입할 때 안내된 가격으로 유료 구독이 자동으로 시작됩니다. 크레딧은 영상을 만들 때마다 빠지므로, 생성하기 전에 비용 안내를 확인하고 진행하세요. 이 영상은 협찬 영상입니다.
