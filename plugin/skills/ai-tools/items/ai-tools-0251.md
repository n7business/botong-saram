# 반복해서 만들 콘텐츠는 첫 결과물을 마음에 들 때까지 고친 뒤 스킬로 만들어 두면, 이후에는 같은 디자인과 품질로 빠르게 찍어 낼 수 있다.

👤 한 사람이 말함 · 짐코딩 (@gymcoding)

첫 결과물은 프롬프트로 고치거나 코드 편집기에서 직접 수정하며 완성한다. 완성본을 템플릿으로 삼아 스킬 크리에이터에 같은 디자인 스타일로 만드는 스킬을 요청한다. 공용 리소스는 루트에 두고, 나머지는 episodes 아래 '연월일_주제' 폴더에 나눠 관리한다. 내용이 마음에 들지 않으면 해당 결과물을 고치고, 레이아웃 자체가 마음에 들지 않으면 스킬을 수정한다. 스킬은 테스트 케이스 2~3개로 검증하며 만드는 것이 좋고, 만든 직후에는 세션을 재시작해야 인식된다.
