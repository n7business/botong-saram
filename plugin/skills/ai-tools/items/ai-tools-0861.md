# AI가 만든 초안을 사람이 고쳤다면 고친 이유를 메신저에 말로 남기고 끝내지 말아야 한다. 같은 실수를 기계적으로 막는 차단 규칙(린트) 한 줄로 바로 규칙 파일에 쌓아야 한다.

👤 출처 1곳 · 지피터스 GPTers

AI 초안을 고칠 때마다 '왜 고쳤는지'를 팀 규칙 파일에 차단 규칙 한 줄로 적습니다. 예를 들면 '자막 한 줄 14자 초과 금지', '근거 없는 과장 수치 금지' 같은 것입니다. 말로 적은 지침은 맥락이 조금만 바뀌어도 AI가 자주 어기지만, 기계가 검사하는 규칙은 매번 똑같이 적용됩니다. 화자가 인용한 개발자 사례에서는 차단 규칙이 4개월 동안 7개에서 167개로 늘면서 작업 산출량이 계단식으로 올랐습니다. 다만 화자 회사의 비개발 업무 적용은 아직 설계 단계이고 효과를 재 본 수치는 없습니다.
