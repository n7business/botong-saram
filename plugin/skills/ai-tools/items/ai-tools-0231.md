# 앱 광고는 콘텐츠나 게임에 몰입한 순간에 전면으로 띄우지 말고, PiP나 스퀴즈백처럼 몰입을 깨지 않는 포맷을 써야 사용 경험을 유지할 수 있다.

👤 한 사람이 말함 · 조코딩 JoCoding

발표자들은 유저가 광고를 무조건 싫어한다는 것은 오해이고 문제는 타이밍이라고 봅니다. 몰입 중 갑자기 뜨는 전면 광고가 최악입니다. PiP는 유튜브 작은 창처럼 콘텐츠 이용을 유지한 채 광고를 보여 줍니다. 스퀴즈백은 기존 화면을 살짝 줄이고 가장자리에 광고를 띄웁니다. 광고 플랫폼 관련 발표이므로 포맷의 효과는 내 앱에서 리텐션과 함께 시험해 확인합니다.
