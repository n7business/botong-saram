# 세금계산서와 통장 내역 같은 매출 자료를 에이전트에 넘기면 수익 종류별 비중을 계산해 엑셀과 그래프로 정리하게 할 수 있지만, 결과는 사람이 최종 검토해야 한다.

👤 한 사람이 말함 · 조코딩 JoCoding

화자는 세금계산서와 통장 내역 같은 매출 자료를 에이전트에게 모두 넘겼습니다. 에이전트는 수익 비중 같은 통계를 계산해 엑셀로 정리했습니다. 유튜브 수익, 브랜디드 콘텐츠 광고 수익 등을 종류별로 나누고 그래프도 그렸습니다. 다만 화자는 최종 검토는 사람이 해야 한다고 말합니다. 한 사람의 경험이며 계산 정확도를 따로 검증한 수치는 제시되지 않았습니다.
