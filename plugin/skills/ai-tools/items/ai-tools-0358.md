# AI에게 요청할 때 적은 작업 조건을 결과 검토 기준으로 그대로 쓰면, 같은 내용을 두 번 쓰지 않고도 결과를 쓸 수 있는지 판단할 수 있다.

👤 한 사람이 말함 · 직장인 AI 업무 자동화 | 라핀

결과물이 나와도 요청이 하나 빠지거나 날짜가 틀리면 고쳐야 하므로 쓸 수 있는지 판단할 조건이 필요합니다. 별도의 검토 기준을 길게 쓰지 말고 요청에 적은 조건을 그대로 확인합니다. 메일 정리 표라면 메일 하나에 든 요청이 모두 있는지, 정한 항목과 순서대로 정리됐는지, 원문에 없는 내용을 만들어 넣지 않았는지를 봅니다. 표를 만드는 일은 AI에게 맡기더라도 그 표를 보고 무엇을 먼저 처리할지는 사람이 결정합니다.
