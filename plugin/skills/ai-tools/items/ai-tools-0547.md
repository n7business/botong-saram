# 클로드 코드의 Code Mode는 실험 기능이라 켠 세션은 Code Mode를 켠 상태에서만 이어 열 수 있고 Remote Control·크롬 연동·데스크톱 앱 이동도 쓸 수 없으므로, 폰으로 이어 할 작업에는 켜지 말고 여러 파일을 똑같이 고치는 일 같은 반복 작업에서만 시험해야 한다.

🏛 공식 발표 · Claude Code 릴리스 노트 (CHANGELOG)

Code Mode는 클로드가 도구를 하나씩 부르는 대신 자바스크립트 코드를 짜서 여러 도구 호출을 한 번에 실행하는 기능입니다. 기본값은 꺼짐이고 실험 기능이라 언제든 바뀌거나 없어질 수 있습니다. 여러 파일에 걸친 반복 수정, 결과를 걸러서 봐야 하는 검색, 동시에 돌려도 되는 명령 여러 개처럼 도구 호출이 많은 일에 쓰라고 안내됩니다. 다만 켠 세션은 Code Mode를 켠 채로만 다시 이어 열 수 있고, Remote Control·Claude in Chrome·컴퓨터 사용을 쓸 수 없으며, 데스크톱 앱이나 백그라운드 세션으로 옮기지도 못합니다. 코드가 한 번에 10분을 넘기면 멈춥니다. 터미널 대화형 세션에서 네이티브 설치판 v2.1.323 이상일 때만 쓸 수 있고, VS Code 패널·데스크톱 앱·클라우드 세션에서는 쓸 수 없습니다.
