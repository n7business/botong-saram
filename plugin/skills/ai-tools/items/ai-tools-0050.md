# 비용이 중요한 에이전트 작업에는 GPT 6.1 테라(중형)를 쓰면 대형 모델 솔보다 에이전트 벤치마크 점수가 높으면서 가격은 훨씬 싸다.

👤 한 사람이 말함 · 수치 근거 · 조코딩 JoCoding

GPT 6.1은 솔(대형)·테라(중형)·루나(소형) 세 등급으로 나왔다. 에이전트 벤치마크에서 테라가 대형 모델 솔보다 점수가 높았고 가격도 더 싸서, 큰 모델이 무조건 좋은 것은 아니다. 테라는 51점까지 올랐고, 비슷한 급인 클로드 소네트가 약 10달러인 데 비해 테라는 0.96달러 수준이다. 반복 호출이 많은 자동화·수집·분류 작업처럼 가성비가 중요한 일에는 테라를 우선 시험한다. 품질이 부족한 작업에만 상위 모델로 올린다.
