# 실제 고객 데이터와 운영 데이터베이스는 AI에게 읽고 정리하는 데까지만 맡기고 사람 확인 없이 직접 고치게 하지 말아야, 다른 곳까지 흔드는 사고를 막을 수 있다.

👤 한 사람이 말함 · 요즘IT

오래 얽힌 서비스에서는 AI가 구조를 다 파악하지 못한 채 데이터를 건드려 다른 곳까지 망가뜨릴 수 있습니다. 그래서 처음에는 엑셀 입력 실수 줄이기나 유지보수 문서 최신화처럼 서비스를 직접 건드리지 않는 작고 귀찮은 일부터 맡깁니다. 사례의 조직은 최소 2주가 걸렸을 문서 정리를 이틀 만에 끝낸 뒤 회의적이던 여론이 바뀌었습니다. 이 선은 사례 작성자가 지금 수준에서 그은 기준이므로, 도구가 달라지면 다시 판단할 수 있습니다.
