# 구글 OAuth 발급처럼 키를 하나씩 넣어야 하는 설정은 브라우저 자동화 도구(Ego Lite 등)에 맡기면 되지만, 계정 로그인·계정 설정·약관 동의 클릭은 사람이 직접 해야 한다.

👤 출처 1곳 · 레인 | AI 바이브코딩 (@Vibe_RaiN)

예전에는 API 키를 받으려면 화면을 하나씩 캡처해 AI에게 무엇을 누를지 묻고 직접 클릭했습니다. 화자는 계획서의 '사용자가 직접 해야 하는 준비' 항목을 브라우저 자동화 도구 Ego Lite에 넘기고 'OAuth 발행해 줘'라고 시켰습니다. 그러자 앱 이름과 정보 등록까지 자동으로 처리됐습니다. 화자에 따르면 기존 Claude computer use보다 이런 브라우저 작업에서 훨씬 빠릅니다. 다만 로그인, 계정 설정, 약관 동의는 사람이 직접 눌러야 합니다.
