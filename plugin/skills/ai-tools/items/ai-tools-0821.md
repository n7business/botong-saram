# AI 검색용 문서 변환 도구는 문서 종류에 따라 골라야 한다. 깔끔한 영수증이나 단순한 표, 글로만 된 문서는 기본 파서로 충분하고, 차트를 이해해야 하거나 표 안에 표가 있고 셀이 여기저기 병합된 한국식 복잡한 표는 VLM 기반 파서를 써야 한다.

👤 출처 1곳 · 테디노트 TeddyNote

모든 문서에 비싼 파서를 쓸 필요는 없다. 발표자에 따르면 깔끔한 영수증이나 단순한 표, 글만 있는 문서는 AutoRAG 기본 파서로 잘 처리된다. 차트, 표 안의 표, 병합 셀이 많은 관공서식 서식처럼 복잡한 문서는 여러 단계를 이어 붙인 기존 파서가 앞 단계에서 표 귀퉁이를 잘라 먹으면 뒤 단계에서 바로잡을 수 없다. 그래서 이런 문서만 골라 문서 전체를 한 번에 보는 VLM 기반 파서(예: 업스테이지 Document Parse 2.0, API와 클로드 코드 MCP 제공)로 돌리면 된다. 발표자가 해당 제품을 만든 회사 소속이므로 성능 비교 주장은 내 문서로 직접 시험해 보고 판단한다.
