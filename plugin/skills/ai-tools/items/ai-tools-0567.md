# 개발자가 아닌 직원이 클로드 코드 같은 AI 코딩 도구로 만든 업무 도구는, 실제 회사·고객 데이터를 다루기 전에 그 도구를 책임질 사람을 한 명 정하고 기존 데이터 접근 권한 규칙을 똑같이 적용해야 한다. 이런 도구는 검토 없이 바로 매일 쓰일 수 있고, 예외 상황을 어떻게 처리하는지 만든 사람도 모를 수 있기 때문이다.

골드만삭스는 클로드 코드 같은 AI 코딩 도구를 엔지니어만 쓰도록 제한했습니다. 이 소식을 분석한 매체는 그 이유로 검토 없이 쓰이는 코드, 부서 간 정보 차단, 코드를 이해하는 사람의 부재, 사용량 비용을 꼽았습니다. 작은 사업장이라도 직원이 AI로 만든 스크립트가 고객 정보나 장부를 매일 건드리기 시작하면 책임자를 정해 두세요. 코드가 프롬프트 한 줄에서 나왔더라도 데이터 접근 권한 규칙은 똑같이 지켜야 합니다. 도구를 거둬들일 때는 직원들이 그 도구로 무슨 일을 했는지 기록해 대체 수단을 마련해야 합니다.
