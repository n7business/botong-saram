# 에이전트가 '기억하겠습니다'라고 답해도 믿지 말고 메모리 파일을 직접 열어 보고, /context로 실제로 들어간 내용을 확인하고, 새 세션에서 설명 없이 다시 시켜 봐야 정말 저장됐는지 알 수 있다.

👤 한 사람이 말함 · 샘 호트만 : AI 엔지니어의 시선 (@ai.sam_hottman)

같은 대화 안에서 지시가 반영되는 것은 그 내용이 아직 컨텍스트에 남아 있어서일 뿐, 저장됐다는 증거가 아닙니다. 다음 세 가지를 확인하세요. 첫째, 메모리 파일을 직접 엽니다. 둘째, /context로 실제로 들어간 내용을 봅니다. 셋째, 새 세션에서 다시 설명하지 않고 같은 일을 시켜 봅니다. 저장된 내용이 내 말과 미묘하게 다를 수 있으니(소문자 서명이 대문자로 저장된 사례) 파일 내용까지 대조하세요. 결과가 마음에 안 들면 대화창에서 다시 설명하지 말고 해당 지침 파일을 고칩니다.
