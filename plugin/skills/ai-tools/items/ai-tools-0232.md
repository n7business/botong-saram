# 앱 광고 수익화는 애드몹 SDK와 파이어베이스 애널리틱스 SDK로 시작하고, 파이어베이스 리모트 컨피그를 쓰면 앱 업데이트 없이 특정 유저에게 다른 시나리오를 보여 줄 수 있다.

👤 한 사람이 말함 · 조코딩 JoCoding

광고용 애드몹 SDK와 분석용 파이어베이스 애널리틱스 SDK를 넣는 것이 출발점입니다. 앱 업데이트 없이 유저별로 다른 시나리오를 보여 주려면 파이어베이스 리모트 컨피그를 씁니다. 발표에서는 개발자라면 일주일 안에 넉넉히 끝나고 바이브 코딩이면 30분~1시간도 가능하다고 했습니다. 애드몹 SDK 하나로 해외 법인 없이 전 세계 유저에게 광고를 낼 수 있다고도 설명합니다. 기본 최적화는 SDK만으로 돌아가지만 고급 최적화에는 따로 시간이 듭니다.
