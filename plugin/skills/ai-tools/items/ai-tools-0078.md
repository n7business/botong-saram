# Claude Code 모델은 기본값(default)으로 두고 쓰되, 사용량을 아끼고 싶을 때만 Sonnet으로 바꾸고, 20달러 요금제라면 Opus와 Sonnet을 오가며 쓴다.

👤 한 사람이 말함 · 서울대 한범 교수의 AI 바이브코딩 (@ProfHanBuhm)

Claude Code에서 /model을 입력하면 모델을 고를 수 있다. 특별한 이유가 없으면 기본값(default)으로 두고, 한도가 아깝다 싶을 때 Sonnet으로 내린다. 100달러 요금제에서는 추가 모델이 보이지만, 20달러 요금제라면 Opus와 Sonnet 둘을 작업 성격에 따라 오가며 쓰는 것으로 충분하다. 모델을 바꾸는 일은 세션 시작 때 정하는 편이 캐시 낭비를 줄인다.
