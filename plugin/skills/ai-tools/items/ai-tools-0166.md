# 코드 저장소가 없는 사람도 v2.1.318의 No repository 옵션을 고르면 Anthropic 호스팅 환경에서 저장소 선택 없이 Claude Code 클라우드 세션을 시작할 수 있다.

🏛 공식 발표 · Claude Code 릴리스 노트 (CHANGELOG)

v2.1.318에서 클라우드 세션에 No repository 옵션이 추가됐다. Anthropic이 호스팅하는 환경이라면 저장소를 고르지 않고 세션을 시작할 수 있다. 저장소가 없어서 클라우드 세션을 쓰지 못했다면 이 옵션을 고른다. 자체 호스팅 환경은 이 변경 내용의 대상으로 적혀 있지 않다.
