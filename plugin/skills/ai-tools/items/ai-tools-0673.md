# 비개발 직원 여럿이 AI로 사내 도구를 함께 고치게 할 때는 자동 테스트(E2E)를 통과해야만 반영되게 막고, 작업은 복제한 격리 공간에서만 하게 해야 하는데, 그래야 직원들이 망가뜨릴 걱정 없이 시도했기 때문이다.

👤 출처 1곳 · 요즘IT

한 명을 도울 때와 달리 여러 명이 같은 시스템 위에서 AI로 작업하면 서로의 작업이 엉킵니다. 사례에서는 '결재'라는 같은 단어 때문에 AI가 전자결재를 고치다가 근태관리의 결재 정책을 끌어오기도 했습니다. AI가 작업마다 먼저 읽는 공통 문서와 데이터 구조 문서를 만들어 두어야 합니다. 대화마다 코드를 복제한 격리 공간에서만 고치게 하고, 자동 테스트를 통과해야 배포되게 막습니다. 이런 안전장치가 있으면 직원들이 마음 놓고 도구를 씁니다.
