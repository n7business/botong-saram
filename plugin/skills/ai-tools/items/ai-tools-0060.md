# Claude Code 사용량은 /usage로 보되 구독자는 플랜 한도만 읽고 세션 달러 추정치를 추가 결제액으로 오해하지 말며, 백그라운드 에이전트를 많이 쓰면 상태 요약 호출 비용을 줄이기 위해 2.1.311 이상으로 업데이트한다.

대화창에 /usage를 입력하면 사용량이 나온다. 프로·맥스 구독자는 플랜에 포함된 사용량을 얼마나 썼는지 보여 주는 표시를 보면 되고, 세션의 달러 추정치는 토큰 수에 요율을 곱한 참고값이라 그만큼 추가 결제된 것이 아니다. API 사용자는 /usage의 Session에서 토큰과 추정 비용을 보고 실제 청구액은 클로드 콘솔과 대조한다. 백그라운드 에이전트의 작업을 짧게 보여 주는 '상태 요약'도 모델을 호출하는데, 한 공개 분석에서는 전체 추정 비용의 16.4%, 개발팀 설명은 전체 평균 약 2%·터미널 약 6%였다. 긴 작업을 여러 에이전트에 맡기는 사용 패턴이면 비중이 커질 수 있으니, 상태 요약이 캐시를 못 쓰는 경우를 고친 2.1.311 이상인지 claude --version으로 확인한다. 요약 타이머를 멈추는 비공식 차단 스크립트는 업데이트 때 다시 호출이 생기고 에이전트 상태 표시도 갱신되지 않으므로 검증 없이 쓰지 않는다.
