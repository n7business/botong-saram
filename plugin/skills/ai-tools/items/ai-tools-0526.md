# VS Code에서 클로드 코드 에이전트를 돌리는 중에 다른 프로젝트 폴더로 옮기려면 파일 > 폴더 열기를 쓰지 말고 새 창(Ctrl+Shift+N, 맥은 Command+Shift+N)을 띄워 열어야 하는데, 같은 창에서 폴더를 바꾸면 그 창에서 돌던 에이전트가 모두 멈추기 때문이다.

👤 한 사람이 말함 · 서울대 한범 교수의 AI 바이브코딩 (@ProfHanBuhm)

VS Code 한 창에서 클로드 코드 에이전트에게 일을 맡겨 둔 상태라면, 다른 저장소(폴더)를 열 때 파일 > 폴더 열기나 최근 항목 열기를 쓰지 마세요. 이 방법은 지금 창의 작업 폴더를 바꾸기 때문에 그 창에서 돌던 에이전트가 모두 멈춥니다. 대신 파일 > 새 창이나 Ctrl+Shift+N(맥은 Command+Shift+N)으로 새 창을 띄우고, 거기서 다른 폴더를 여세요. 그러면 기존 창은 하던 일을 계속하고, 새 창에서도 에이전트를 따로 띄울 수 있습니다.
