# 편집 도구 없이 제품·기능 소개 영상을 만들고 싶다면 클로드 코드나 코덱스에 huashu-motion 스킬을 설치하고 웹사이트 주소를 주면 시안 세 가지를 받아 고르고 장면을 클릭해 고칠 수 있지만, macOS에서만 시험된 공개 직후의 개인 프로젝트라는 점은 감안해야 한다.

👤 한 사람이 말함 · 요즘IT

huashu-motion은 AI 코딩 도구에 '우리 제품 30초 출시 영상 만들어줘. 웹사이트는 OOO이야'라고 말하면 사이트를 읽고 방향이 다른 시안 세 가지를 보여 준 뒤 영상과 배경음악을 만드는 무료(MIT) 스킬입니다. 설치는 'npx skills add alchaincyf/huashu-motion' 한 줄이고 Node 22 이상, Chrome, FFmpeg가 필요하며 빠진 것은 AI에게 설치를 맡기면 됩니다. 영상 생성 AI가 아니라 웹 애니메이션 코드로 그리기 때문에 글자나 숫자 하나만 바꿔도 나머지 장면이 유지되고, 편집기에서 C 키를 누르고 화면을 클릭해 의견을 적으면 그 부분만 고칩니다. 대신 사람이 나오는 실사 장면은 만들 수 없고, AI 사용량은 쓰는 AI 코딩 도구 요금제에서 차감됩니다. 4초가 넘는 영상 끝에는 'Made with huashu-motion' 문구가 붙으니 AI에게 빼 달라고 해야 하며, 만든 사람이 macOS에서만 실제로 테스트했다고 밝힌 공개 열흘 된 개인 프로젝트입니다.
