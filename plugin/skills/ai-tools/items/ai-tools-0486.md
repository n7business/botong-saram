# 클로드 코드 설치 명령은 내려받는 동안 진행 상황을 보여 주지 않으므로 멈춘 줄 알고 끊지 말고, 끝나면 새 터미널 창을 열어 claude --version으로 버전 번호가 나오는지 확인해야 한다.

🏛 공식 발표 · Claude Code 공식 문서

설치 명령을 실행하면 다운로드 중에 진행 표시가 나오지 않습니다. 멈춘 것처럼 보여도 끝날 때까지 기다리세요. 설치가 끝나면 원래 창이 아닌 새 터미널 창을 열고 claude --version을 실행합니다. 버전 번호가 나오면 정상입니다. 'claude를 찾을 수 없다'는 메시지가 나오면 설치 폴더가 아직 PATH에 등록되지 않은 것이니 공식 문제 해결 문서의 'Fix your PATH' 항목을 따라 고치면 됩니다.
