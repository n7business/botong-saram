# 에이전트에 도구를 추가할 때는 도구만 연결하지 말고 언제 그 도구를 쓸지도 시스템 프롬프트에 함께 적어야 한다.

👤 한 사람이 말함 · 테디노트 TeddyNote

도구를 목록에서 추가하기만 하면 언제 써야 하는지는 시스템 프롬프트에 따로 적어야 합니다. 영상의 빌더에서는 대화로 설정을 고치는 Fix 에이전트에게 맡기면 도구 추가, 도구 가이드라인, 대화 시작 문구가 한 번에 바뀝니다. 그런 기능이 없는 도구라면 도구를 붙인 뒤 사용 시점을 프롬프트에 직접 적습니다. Fix 에이전트는 화자가 만든 제품의 기능입니다.
