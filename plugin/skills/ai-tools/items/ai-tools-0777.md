# Nginx를 11월 18일 보안 패치 버전으로 올린 뒤에는 Nginx를 완전히 껐다가 다시 켜야 한다. 컨테이너 안에서 돌리고 있어도 안심하면 안 된다.

👤 출처 1곳 · 수치 근거 · 코드깎는노인

11월 18일 공개된 '엔진엑스 투 루트' 버그 5개는 모두 위험도 9.2점(치명적)입니다. 리눅스 커널 버그와 이어 쓰면 서버의 최고 관리자(루트) 권한까지 빼앗길 수 있습니다. 서버를 관리한다면 F5가 같은 날 낸 새 버전으로 올려야 합니다. 설치한 뒤에는 Nginx를 완전히 껐다가 다시 켜야 예전 프로그램 대신 새 버전이 돌아갑니다. 티오리의 시험에서는 컨테이너 안의 Nginx를 공격해 컨테이너 밖 서버의 루트 권한까지 얻었습니다. 공격 재연 코드는 이미 공개됐습니다. 웹사이트를 이용하기만 하는 사람은 직접 할 일이 없습니다.
