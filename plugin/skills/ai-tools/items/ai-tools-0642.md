# 여러 컴퓨터를 오가며 AI 코딩 도구를 쓴다면 작업 인계 내용을 각 기기의 AI 메모리에만 두지 말고, 프로젝트 저장소 안의 인계(핸드오프) 폴더에 문서로 남겨야 한다. 한 기기의 세션이 만든 파일과 메모리는 다른 기기로 넘어가지 않기 때문이다.

👤 출처 1곳 · 요즘IT

클로드 코드 같은 도구의 세션 메모리와 작업 파일은 그 기기에만 남는 경우가 많습니다. 화자는 맥북, 맥미니, 윈도우 PC를 오가며 일하다 이 문제를 겪었습니다. 그래서 여러 작업에 걸친 내용과 인계 사항은 같은 저장소의 핸드오프 폴더에 기록하기로 했습니다. 그러자 어느 기기에서 세션을 열어도 같은 맥락으로 이어서 작업할 수 있었습니다. 컨텍스트가 가득 차서 새 세션으로 넘길 때도 이 인계 문서를 씁니다.
