# LangSmith Agent Builder에서 도구 실행 전에 직접 확인하려면 Tool Approval을 켜 두어야 하며, 끄면 묻지 않고 바로 실행된다.

👤 한 사람이 말함 · 테디노트 TeddyNote

오른쪽 상단의 Tool Approval을 켜 두면 도구를 실행할 때마다 먼저 물어봅니다. 끄면 묻지 않고 바로 실행합니다. 영상에서는 슬랙 발송 요청 뒤 Accept를 누르자 실제로 메시지가 발송됐습니다. 메시지 발송처럼 외부로 나가는 동작을 시험할 때는 켜 두고 내용을 확인하는 편이 안전합니다. 2025년 11월 영상 기준이므로 현재 메뉴는 달라졌을 수 있습니다.
