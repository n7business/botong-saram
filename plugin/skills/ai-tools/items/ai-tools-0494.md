# 힉스필드 Genjutsu로 영상 속 인물을 바꿀 때 얼굴만 바꾸고 나머지 장면은 그대로 두려면 Object Swap을 골라야 하는데, Motion Transfer는 동작만 남기고 나머지를 새로 만들어 바뀌는 폭이 크기 때문이다.

힉스필드 비디오 메뉴의 Genjutsu는 교체 방식으로 Motion Transfer와 Object Swap 두 가지를 제공한다. Object Swap은 선택한 부분(예: 얼굴)만 바꾸고 배경·옷·다른 인물 등 나머지는 그대로 둔다. Motion Transfer는 원본 영상의 동작만 가져오고 나머지는 새로 만들어서 결과가 원본과 더 많이 달라진다. 제품·의류 영상처럼 원본 장면을 살려야 하면 Object Swap을, 동작만 빌려 장면을 새로 꾸미려면 Motion Transfer를 고른다.
