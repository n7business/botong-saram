# AI 에이전트에게 구현을 맡길 때는 필요한 자료와 함께 내가 아는 권한 제약, 아직 방법이 정해지지 않은 부분, 이번에 하지 않을 작업을 요청문에 적고, 값을 구할 수 없으면 임의로 채우지 말고 먼저 묻게 해야 한다.

👤 한 사람이 말함 · 요즘IT

사람에게는 당연한 조회 제약이나 작업 순서를 AI는 모릅니다. 그래서 요청할 때 필요한 자료만 주지 말고 '이 정보는 지금 계정으로 조회할 수 없다', '이 기능은 이번에 만들지 않는다', '배포는 하지 않는다'처럼 제약과 제외 범위를 함께 적어야 합니다. 특히 필요한 값을 구할 수 없을 때는 임의로 채우지 말고 방법부터 확인해 달라고 적어 두세요. 반복해서 쓰는 지침이라면 지시 파일에 정리해 두면 됩니다. 이 방식은 글쓴이가 앞으로 적용하려는 계획 단계라는 점을 감안하세요.
