# Higgsfield Supercomputer로 만든 사이트를 로그인하지 않은 사람도 링크로 열게 하려면 커뮤니티 피드라는 공개 게시판에 올려야 하므로, 고객 정보나 내부 자료가 들어간 사이트는 이 방식으로 공개하지 말아야 한다.

👤 출처 1곳 · 코드깎는노인

Higgsfield에서는 사이트를 '앱'이라고 부르며, 외부인이 링크로 열려면 커뮤니티 피드에 게시해야 합니다. 화자 사례에서는 클로드가 이 게시까지 스스로 처리했습니다. 즉, 링크 공개는 공개 게시판 노출과 같아서 사이트와 함께 만든 강사 사진·영상 같은 에셋이 남에게 보일 수 있습니다. 게시된 앱은 Supercomputer → 앱 → 내 앱 → 게시된 앱에서 다시 찾을 수 있습니다.
