# 코덱스 사용량을 늘리려고 한 기기에서 유료 계정 여러 개를 돌려 쓰면 계정이 잠길 수 있으므로, 한도가 부족하면 계정을 늘리지 말고 상위 요금제나 크레딧으로 해결한다.

👤 한 사람이 말함 · 조코딩 JoCoding

오픈AI는 한 기기에서 추가 코덱스 사용을 위해 유료 계정 여러 개를 번갈아 쓰는 것을 제한하며, 결제 카드에도 제한이 있다. 예를 들어 코덱스를 10개 구독해 차례로 쓰면 계정이 잠길 수 있다. 계정이 잠기면 작업 중인 프로젝트 접근까지 막히므로 소규모 사업자에게는 손실이 크다. 한도가 부족하면 계정을 늘리는 대신 상위 요금제로 올리거나 API 크레딧을 쓰는 것이 안전하다. 화자는 구독 한도를 다 쓰면 크레딧으로 유도하는 전략으로 본다.
