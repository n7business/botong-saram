# 클로드 코드에 쓰는 규칙(CLAUDE.md)·설정·MCP 연결은 터미널·VS Code·데스크톱 앱·웹마다 따로 만들 필요가 없다. 저장소에 한 번 만들어 두면 어느 화면에서 쓰든 그대로 적용된다.

🏛 공식 발표 · Claude Code 공식 문서

공식 문서에 따르면 클로드 코드의 모든 사용 화면은 같은 엔진에 연결됩니다. 그래서 저장소에 둔 CLAUDE.md 파일, 설정, MCP 서버는 어느 화면에서든 똑같이 작동합니다. 사무실에서는 데스크톱 앱, 밖에서는 웹이나 휴대폰처럼 화면을 바꿔 써도 업무 규칙은 프로젝트 저장소 한 곳에서만 관리하면 됩니다.
