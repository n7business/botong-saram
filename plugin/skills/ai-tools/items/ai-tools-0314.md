# 개인정보가 든 파일을 클로드에게 읽힐 수 있다면 claude.ai 설정에서 'AI 모델 개선 돕기'를 꺼야, 내 데이터가 모델 훈련에 쓰이지 않는다.

👤 한 사람이 말함 · 서울대 한범 교수의 AI 바이브코딩 (@ProfHanBuhm)

claude.ai 왼쪽 아래 내 이름을 누르고 설정 > 개인 정보 보호로 들어가 'AI 모델 개선 돕기'를 끈다. 메뉴 위치는 영상 시점 기준이다. 화자에 따르면 일상 업무 파일에는 주민등록번호나 주소가 들어 있을 수 있고, 훈련 사용을 허락하면 그 내용이 다른 사람의 대화에서 나올 가능성도 배제하기 어렵다. 화자는 이 설정을 끄면 클로드 코드와 대화창의 내용이 모두 훈련에 쓰이지 않는다고 설명한다. 다만 답변을 만들려면 데이터가 서버로 전송되므로, 끄더라도 서버에 30일간 머무는 것은 막을 수 없다고 한다.
