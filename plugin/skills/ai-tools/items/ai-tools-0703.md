# 챗봇 시험 질문은 머릿속으로 지어내지 말고 실제 손님 문의 기록이나 받은 민원에서 뽑아야 하며, 한 번 만들고 끝내지 말고 새로 들어온 사례로 계속 보태야 한다. 지어낸 질문은 AI가 통과하기 너무 쉽고 실제 손님 말투와도 다르기 때문이다.

🏛 공식 발표 · Anthropic Engineering 블로그

실제 사용 기록이 없으면 공개된 자료, 사고·민원 사례, 현장 실무자 인터뷰를 바탕으로 시나리오를 만듭니다. 손님의 행동은 시간이 지나면 바뀌므로, 운영하면서 발견한 이상한 문의나 문제 대화를 시험 목록에 계속 추가합니다. 실제로 쓰는 환경과 같은 언어, 같은 화면(웹·카카오톡 등), 같은 시스템 프롬프트로 시험해야 결과를 믿을 수 있습니다.
