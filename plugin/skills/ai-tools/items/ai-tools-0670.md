# 메일·통화·팩스 기록을 AI로 한곳에서 검색되게 만들 때는 광고 팩스 같은 잡음을 기본 검색에서 빼 두고 필요할 때만 포함하게 해야 하는데, 광고 255건을 함께 넣었더니 검색 결과 위쪽이 광고로 채워져 도구를 덜 열게 됐기 때문이다.

👤 출처 1곳 · 요즘IT

업무 기록을 모으는 도구는 무엇을 넣을지보다 무엇을 안 보여 줄지가 더 중요합니다. 팩스로 들어온 광고처럼 쓸모없는 기록이 섞이면 검색 결과가 지저분해지고, 만든 사람조차 그 도구를 안 열게 됩니다. 잡음은 따로 분류해 기본 검색에서 빼고, 필요할 때만 포함하도록 옵션을 둡니다. 검색 결과를 계속 믿을 수 있도록 매주 20분쯤 어긋난 기록과 묵은 할 일을 정리하는 시간도 잡아 두어야 합니다.
