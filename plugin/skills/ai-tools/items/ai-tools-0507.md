# AI 에이전트에게 일을 맡길 때는 '무엇을 할지'라는 목표만 적지 말고 '어느 수준까지 해야 하는지'라는 기준을 함께 적어야 하는데, 기준이 모호하면 에이전트가 일을 끝내도 결과물 수준이 기대에 못 미치기 때문이다.

👤 한 사람이 말함 · 일잘러 장피엠

에이전트에게 주는 요청문에는 목표와 기준 두 가지를 분명히 적습니다. 목표는 해야 할 일(예: 그림판으로 사진을 그려 저장)이고, 기준은 결과물이 갖춰야 할 수준(예: 원본과 최대한 똑같이)입니다. 실험에서 목표만 준 첫 결과는 저장까지 했지만 완성도가 낮았고, '원본과 최대한 똑같이'라는 기준을 더하자 다른 도구를 골라 원본에 더 가깝게 그렸습니다. 다만 기준을 넣었다고 바로 원하는 수준에 이르지는 않을 수 있으므로 결과를 보고 기준을 더 구체적으로 다듬어야 합니다.
