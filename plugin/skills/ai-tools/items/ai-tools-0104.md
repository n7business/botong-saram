# Claude Code는 실행한 폴더를 기준으로 파일을 읽고 고치고 만들기 때문에, 반드시 작업할 프로젝트 폴더(카드뉴스·PPT 작업이라면 그 작업 폴더)로 이동한 뒤 그 안에서 실행한다.

👤 한 사람이 말함 · 짐코딩 (@gymcoding)

Claude Code를 실행한 디렉터리가 파일을 읽고, 고치고, 새로 만드는 기준이 됩니다. 개발이라면 해당 프로젝트 폴더에서, 카드뉴스나 PPT 같은 마케팅 자동화라면 그 작업 폴더에서 실행하세요. 처음 실행할 때 나오는 디렉터리 확인 질문은 한 번만 'Yes'를 누르면 됩니다. VS Code·Cursor 같은 편집기로 작업 폴더를 열고 내장 터미널에서 실행하면, Claude Code가 만든 HTML 같은 파일을 바로 열어 볼 수 있어 편합니다.
