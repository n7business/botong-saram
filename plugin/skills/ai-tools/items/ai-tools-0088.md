# 반복 접수되는 거래처 서류를 AI 에이전트로 읽히려면 업체마다 다른 양식을 그대로 받지 말고 우리 쪽 통일 양식(가능하면 3장 내외로 통합)으로 제출받는다.

👤 한 사람이 말함 · 양실장의 바이브코딩대학 (@VibecodingUniversity)

업체마다 서류 양식이 다르면 OCR과 에이전트가 항목을 잘못 읽거나 데이터가 쌓여도 비교가 안 된다. 해커톤 팀은 장기적으로 업계 서류 양식을 통일해 에이전트가 잘 읽고 데이터 마이닝하기 좋게 해야 한다고 보고, 실험으로 서류를 3장 정도로 통합해 테스트했다. 매번 써야 하는 서류는 템플릿으로 만들어 순서대로 안내하고 진행률을 바로 보이게 하며, 서명란은 한곳으로 모은다. 미리보기 예시는 처음엔 켜 두되 기본 내용이 채워진 뒤에는 값으로 저장해 번거로움을 줄인다. 회사마다 다른 직함 같은 항목은 직접 고칠 수 있게 열어 둔다.
