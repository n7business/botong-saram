# 클로드에 Higgsfield를 커스텀 커넥터로 연결할 때는 안내 페이지 주소(higgsfield.ai/mcp)가 아니라 https://mcp.higgsfield.ai/mcp를 넣어야 하고, 작업 메시지를 보내기 전에 입력창의 커넥터 목록에서 Higgsfield가 켜져 있는지 확인해야 한다.

👤 출처 1곳 · 코드깎는노인

클로드 설정 → 커넥터 → 추가 → 커스텀 커넥터 추가 순서로 들어가 이름은 Higgsfield, URL은 https://mcp.higgsfield.ai/mcp로 넣습니다. 이 주소는 모델 목록과 워크플로를 정리한 안내 페이지(higgsfield.ai/mcp)와 다르므로 헷갈리지 않아야 합니다. API 키를 따로 발급받을 필요는 없고 Higgsfield에 로그인만 하면 연결됩니다. 연결한 뒤에도 입력창의 더하기 버튼 → 커넥터에서 Higgsfield가 꺼져 있으면 이미지·영상·음악 도구를 쓰지 못하므로 보내기 전에 꼭 확인합니다. 화자의 영상은 Higgsfield 협찬입니다.
