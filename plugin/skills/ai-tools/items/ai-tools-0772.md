# AI로 만든 영상에 대사가 들어 있으면 소리는 사람이 직접 들어 확인해야 하고, 숫자가 이상하게 발음되면 대사 속 숫자를 한글로 바꿔 다시 만들게 하면 된다.

👤 출처 1곳 · 코드깎는노인

클로드는 장면마다 그림은 직접 확인했지만, 소리는 들을 수 없으니 대사는 직접 들어 보고 확인해 달라고 알렸습니다. 화자 사례에서는 대사 속 '10시', '7시'가 이상하게 발음됐습니다. 발음이 이상하다고 말하자 대사의 숫자를 한글로 바꿔 해당 장면만 다시 만들었습니다. 영상 속 손글씨가 알아볼 수 없는 글자로 나왔을 때도 '또렷한 한글로' 고쳐 달라고 해서 그 그림과 장면만 다시 만들었습니다. 그러니 AI가 확인을 마쳤다고 해도 소리와 화면 속 글자는 사람이 마지막으로 확인해야 합니다.
