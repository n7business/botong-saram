# Claude Agent SDK로 만든 제품에는 'Claude Code'라는 이름이나 이를 흉내 낸 시각 요소를 쓰면 안 되고, 자체 브랜드를 유지해야 한다.

🏛 공식 발표 · Claude Code 공식 문서

Claude 브랜드 사용은 선택 사항입니다. 쓰려면 'Claude Agent', 'Agents' 메뉴 안의 'Claude', 기존 에이전트 이름이 있을 때의 '{YourAgentName} Powered by Claude' 표기가 허용됩니다. 'Claude Code'와 'Claude Code Agent'라는 표기, Claude Code 브랜드의 ASCII 아트나 이를 흉내 낸 시각 요소는 허용되지 않습니다. 제품은 자체 브랜드를 유지하고 Claude Code나 Anthropic 제품처럼 보이지 않아야 합니다. 준수 여부가 궁금하면 Anthropic 영업팀에 문의합니다.
