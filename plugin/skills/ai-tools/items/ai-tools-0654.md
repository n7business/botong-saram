# 힉스필드에서 AI로 만든 웹사이트를 배포했다면 로그인하지 않은 시크릿 창에서 열어 봐야 한다. 배포만 한 상태에서는 로그인하지 않은 방문자에게 힉스필드 로그인 화면만 나오고, Publish Website로 커뮤니티 피드에 공개해야 로그인 없이 열렸기 때문이다.

👤 출처 1곳 · 코드깎는노인

ChatGPT에 힉스필드 플러그인(MCP)을 연결하거나 힉스필드 슈퍼 컴퓨터를 쓰면 대화만으로 웹사이트를 만들고 배포할 수 있다. 다만 화자 실험에서 Deploy Website로 배포한 사이트는 힉스필드에 로그인한 브라우저에서만 제대로 열렸고, 로그인하지 않은 시크릿 창에서는 로그인 화면만 나왔다. AI도 처음에는 연결된 도구에 로그인 확인을 풀어 주는 설정이 없다며 외부 호스팅으로 옮기자고 제안했다. 하지만 Publish Website로 커뮤니티 피드에 공개하자 시크릿 창에서도 로그인 없이 바로 열렸다. 커뮤니티 피드는 다른 사용자들도 구경하는 공개 게시판이므로, 공개해도 되는 내용인지 먼저 확인해야 한다. 힉스필드 협찬 영상에서 나온 내용이다.
