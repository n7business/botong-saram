# 새 AI 모델로 갈아탈지 판단하려면 인터넷에 답이 없을 법한 나만의 시험 주문을 하나 정해 두고, 새 모델이 나올 때마다 같은 주문으로 비교해야 한다. 이때 결과가 수상하면 미리 아껴 둔 다른 변형 주문으로 다시 확인해야 한다.

👤 출처 1곳 · 코드깎는노인

사이먼 윌리슨은 새 모델이 나올 때마다 '자전거를 타는 펠리컨'을 SVG로 그려 달라는 같은 주문으로 시험한다. 인터넷에 거의 없는 결과물이라 모델이 학습 때 본 것을 따라 할 수 없고, 스스로 생각해야 하기 때문이다. 결과가 의심스러울 때는 '외발자전거 타는 플라밍고' 같은 예비 시험을 꺼내 그 주문만 연습한 것인지 확인했다. 내 업무에서도 자주 하는 일 가운데 까다롭고 공개되지 않은 주문(예: 실제 업무 서식 작성)을 하나 정해 두면 모델을 비교하기 쉽다. 다만 윌리슨도 그림 시험을 잘하는 모델이 꼭 쓸모 있는 모델은 아니게 됐다고 했으므로, 시험 하나의 결과만으로 모델을 판단하지 말아야 한다.
