# AI에게 파일 작업을 맡길 때 컬럼명과 파일 구조는 AI가 직접 확인하게 하고 포함할 데이터와 완료 조건은 사람이 정해야, 설명 품을 줄이면서 AI가 업무 기준을 멋대로 정하는 일을 막을 수 있다.

👤 한 사람이 말함 · 직장인 AI 업무 자동화 | 라핀

컬럼명·값·파일 구조는 파일을 열면 알 수 있으므로 다시 적지 말고 AI가 살펴보게 합니다. 파일에서 확인할 수 있는 내용은 다시 묻지 말고, 파일만 보고 정할 수 없는 업무 기준이 있을 때만 물으라고 지시합니다. 결제 완료 주문만 쓸지, 어떤 숫자와 비교를 볼지, 원본을 남길지처럼 결과를 좌우하는 기준은 사람이 정합니다. 처리 방법처럼 결정하기 어려운 부분은 가장 쉬운 방법을 추천받아도 됩니다.
