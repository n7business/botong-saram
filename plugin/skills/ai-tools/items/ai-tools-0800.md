# AI로 간단한 2D 게임을 만들 때는 게임 코드는 클로드 소네트 5.5로 짜고 캐릭터·배경 그림은 제미나이 앱의 나노 바나나로 따로 뽑으면 비용을 아낄 수 있다. 화자에 따르면 소네트 5.5의 API 요금은 오퍼스 5.5의 절반이다.

👤 출처 1곳 · 윤자동 | AI자동화로 세상을 돕는중 (@yun_ja_dong)

게임 코드는 구독 중인 서비스의 코딩 도구(클로드 코드, 코덱스)로 만들고, 모델은 클로드 소네트 5.5를 쓰면 무난하다고 화자는 권한다. 화자에 따르면 API 요금은 100만 토큰당 입력 2달러, 출력 10달러로 오퍼스 5.5의 절반이다. 캐릭터와 배경 그림은 제미나이 앱의 나노 바나나로 따로 만든다. 다만 화자도 모델별로 2D 게임 품질을 비교한 자료는 찾지 못했다고 밝혔으니 추천 의견으로만 보고, 요금은 공식 가격표에서 다시 확인해야 한다.
