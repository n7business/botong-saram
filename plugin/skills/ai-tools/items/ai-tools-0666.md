# AI로 거래처용 업무 시스템을 만들어 줄 때는 구축비를 한 번에 받는 외주로 팔지 말고, 구축비 없이 월 사용료를 받는 서비스로 제안해야 반복 매출이 생기고 팔기도 쉽다.

👤 출처 1곳 · 양실장의 바이브코딩대학 (@VibecodingUniversity)

화자는 '2천만 원짜리 하나 사세요'보다 '공짜로 만들어 줄 테니 월 200만 원 내세요'가 훨씬 팔기 쉽다고 말합니다. 용역으로 한 번 받고 끝내면 차별화가 어렵지만, 서비스로 바꾸면 반복 매출이 생기고 고객을 붙잡아 둘 수 있습니다. 고객이 월 사용료를 계속 내는 것을 부담스러워하면 서비스를 통째로 사겠다는 매각 제안으로 이어질 수도 있습니다. 화자 회사도 몇천만 원짜리 내부 개선 의뢰를 이 방식으로 제안하고 있다고 합니다.
