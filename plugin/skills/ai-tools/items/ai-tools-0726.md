# AI 영상 프롬프트를 직접 쓰기 전에, 사용할 영상 모델에 맞는 프롬프트 작성법을 AI에게 먼저 알려 주고 원하는 광고를 말로 설명해 프롬프트를 대신 쓰게 해야 한다.

👤 출처 1곳 · 노마드 코더 Nomad Coders

영상 모델마다 잘 알아듣는 프롬프트 형식이 다릅니다. 화자는 여러 영상 모델용 작성 가이드가 담긴 스킬을 AI에게 읽혔습니다. 가이드에는 영상을 타임라인으로 나누는 법, 알맞은 인물이 알맞은 때 대사를 말하게 쓰는 법, 문제가 생긴 초안을 고치는 법이 들어 있습니다. 그 뒤 원하는 광고를 설명하면 AI가 해당 모델에 맞는 형식으로 프롬프트를 써 줍니다.
