# AI로 홈페이지를 만들게 할 때는 배포한 뒤 데스크톱과 모바일에서 실제 사이트를 테스트하고 어색한 곳을 고치라는 지시를 메시지에 함께 적어야 한다.

👤 출처 1곳 · 코드깎는노인

화자는 이미지·영상·음악은 Higgsfield로, 코드는 클로드가, 배포는 Supercomputer로 하라고 역할을 나눠 적은 뒤, 배포 후 데스크톱과 모바일에서 실제 사이트를 테스트해 고치라고 덧붙였습니다. 클로드는 자기가 만든 영상에서 장면을 뽑아 직접 확인했고, 메시지와 다르게 나온 첫 화면 영상과 동작 영상 세 개를 한 번씩 다시 만들었습니다. 검수 지시가 있어야 AI가 스스로 확인하고 고치므로 긴 작업을 맡길 수 있습니다. 다만 최종 확인은 사람이 직접 링크를 열어 해야 합니다.
