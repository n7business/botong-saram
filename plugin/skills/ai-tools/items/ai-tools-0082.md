# Claude Code가 로그인 만료로 멈추면 /login을 입력하고 계정을 고른 뒤 승인을 누르면 바로 복구된다.

👤 한 사람이 말함 · 서울대 한범 교수의 AI 바이브코딩 (@ProfHanBuhm)

Claude Code는 가끔 로그인이 만료되어 명령이 먹지 않는다. 이때 재설치나 설정을 뒤지지 말고 입력창에 /login을 치면 브라우저에서 계정 선택과 승인 화면이 뜬다. 계정을 고르고 승인을 누르면 다시 로그인되어 이전 작업을 이어갈 수 있다.
