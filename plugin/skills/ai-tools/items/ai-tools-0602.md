# Doop 같은 AI 디자인 캔버스에 Codex나 Claude Code를 연결하면 그 서비스의 계정과 구독 조건으로 사용되고 비용이 하나로 합쳐지지 않으므로, 연결하기 전에 권한과 비용 구조를 확인해야 한다.

Doop은 MCP로 Claude Code, Claude, ChatGPT, Codex, Cursor 같은 외부 AI를 연결해 캔버스에서 화면을 만들게 하는 도구입니다. 외부 AI를 연결하면 그 서비스의 계정과 구독 조건이 그대로 적용됩니다. Doop 자체 이용 조건과 외부 AI 사용료는 따로 계산됩니다. 연결 버튼 하나로 모든 AI 기능을 무료로 쓰게 되는 것이 아닙니다. 외부 계정 승인이나 MCP 연결이 낯설다면 첫 작업 전에 어떤 권한을 주는지, 비용이 어디서 나가는지부터 확인하세요.
