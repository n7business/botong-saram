# AI 상담을 도입할 때는 비용만 보지 말고 단순 반복 문의는 AI에, 감정이 섞이거나 복잡한 문의는 사람에게 나눠 맡겨야 상담 품질이 떨어지는 일을 막을 수 있다.

👤 한 사람이 말함 · 수치 근거 · 조코딩 JoCoding

클라르나는 2024년 2월 상담에 AI를 넣었고, 첫 달에 AI가 230만 건(전체 상담의 3분의 2)을 처리했습니다. 처리 시간은 11분에서 2분 아래로 줄었고, 같은 문의를 다시 하는 고객도 25% 줄었습니다. 그런데 감정이 섞이거나 복잡한 문의까지 맡기자 품질이 떨어졌고, 2025년 5월 다시 사람을 채용했습니다. CEO는 비용만 보고 너무 멀리 갔다고 말했습니다. 도입 전에 무엇을 AI에 맡기고 무엇을 사람에게 남길지 먼저 정해야 합니다.
