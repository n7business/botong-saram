# Claude Agent SDK로 만든 내 서비스 이름에 'Claude Code'를 넣거나 클로드 코드처럼 보이게 꾸미지 말고, 'OO Powered by Claude'처럼 표기해야 브랜딩 규정을 어기지 않는다.

🏛 공식 발표 · Claude Code 공식 문서

Anthropic 브랜딩 지침에 따르면 Agent SDK로 만든 제품에 'Claude Code'나 'Claude Code Agent'라는 이름을 붙일 수 없습니다. 클로드 코드를 흉내 낸 ASCII 아트나 디자인 요소도 쓸 수 없습니다. 쓸 수 있는 표기는 'Claude Agent', 'Agents' 메뉴 안의 'Claude', '내 에이전트 이름 Powered by Claude'입니다. Claude 표기 자체는 선택 사항이고, 제품은 자체 브랜드를 유지해야 합니다.
