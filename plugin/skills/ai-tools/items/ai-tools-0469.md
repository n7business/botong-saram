# AI로 만든 시제품이라도 실제 고객 데이터가 들어 있거나 운영 시스템에 연결되어 있다면 운영 서비스처럼 관리해야 하며, 기능을 시험할 때는 실데이터 대신 비식별 데이터나 가짜(목) 데이터를 써야 한다.

👤 한 사람이 말함 · 요즘IT

'잠깐 만들어 본 시제품'이라도 실제 고객 정보가 들어 있거나 운영 중인 시스템에 연결되어 있으면 사고가 났을 때 피해는 운영 서비스와 같습니다. 공유하기 전에 개인정보·인증정보가 노출되지 않는지, 내부 시스템에 연결되어 있지 않은지, 누가 볼 수 있는지 확인하세요. 데이터 처리나 기능 검증이 목적이라면 실데이터를 AI에 넣지 말고 이름·연락처를 지운 비식별 데이터나 가짜 데이터를 만들어 쓰면 됩니다.
