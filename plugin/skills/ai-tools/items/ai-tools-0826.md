# 개발을 모르는 직원에게 회사 AI 도구 연결을 맡길 때는 설치 명령을 하나하나 가르치지 말고, 연결 방법을 지시문으로 정리해 그 직원의 클로드 코드나 코덱스에 넘겨 주면 된다. 발표자 회사에서는 이렇게 하면 에이전트가 알아서 연결하고, 직원은 구글 워크스페이스로 로그인만 하면 끝났다.

👤 출처 1곳 · 테디노트 TeddyNote

비개발 직원은 MCP 서버를 명령줄로 설치하는 단계에서 막히기 쉽다. 연결 주소와 설정 절차를 지시문(인스트럭션) 파일로 만들어 직원의 AI 코딩 도구에 붙여 넣게 하면 도구가 설정을 대신 해 준다. 직원은 회사 계정으로 로그인만 하면 된다. 이때 직원 계정에는 그 직무에 필요한 조회 권한만 주어야 한다.
