# 챗GPT 프로·비즈니스 구독자가 월 최대 500달러 상당의 API 크레딧을 받으려면 구독 7일 뒤 오픈AI 설정의 빌링(결제) 화면에서 'API 크레딧 청구하기'를 직접 눌러 신청해야 하며, 안 쓴 크레딧은 결제 주기가 끝나면 사라진다.

👥 2명이 말함 · 지피터스 GPTers, 조코딩 JoCoding

2026년 11월 3일 확인 기준으로 프로 100은 월 100달러, 프로 200은 200달러, 프로 500은 500달러를 받는다. 비즈니스는 Standard 시트당 20달러, Premium 시트당 100달러를 워크스페이스가 함께 쓰며 전체 한도는 월 500달러다. 플러스, 무료 체험, 엔터프라이즈, 에듀 구독은 대상이 아니다. 구독 계정으로 로그인해 설정의 결제에서 월간 구독 혜택 카드의 조직 연결을 누르고, API 조직을 확인해 활성화한 뒤 API 플랫폼 결제 설정에서 입금을 확인한다. 이 크레딧은 내가 만든 앱·자동화의 API 호출 비용에 쓰는 잔액으로 챗GPT 화면의 사용 한도와 별개이고, 첫 지급액은 결제 기간 중 남은 기간에 비례해 계산된다. 조건은 바뀔 수 있으니 신청 전에 OpenAI 도움말을 다시 확인한다.
