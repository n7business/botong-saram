# AI 시스템 개발을 외주로 맡기거나 맡을 때는 계약서에 '100% 정확한 답변 보장'을 넣지 말아야 한다. 대신 대표 질문 100~200건 기준의 정답 일치율 같은 검수 기준을 적고, 인도 후 영업일 10일 안에 서면 결함 통보가 없으면 검수 승인으로 보는 조항을 넣어야 한다.

👤 출처 1곳 · 양실장의 바이브코딩대학 (@VibecodingUniversity)

AI는 확률로 답을 만들기 때문에 '무결점 답변 보장'에 합의하면 영원히 검수를 통과할 수 없습니다. 과업 범위는 'AI 상담봇 개발'처럼 모호하게 쓰지 말고 화면 목록, 연동할 외부 API 목록까지 정해서 적으세요. 범위 밖의 변경은 공식 요청서로 추가 비용과 기간을 합의한 뒤 반영합니다. 무상 하자보수는 코드 결함으로 한정하세요. 호스팅비·LLM 토큰 요금·자료 재구축은 별도 유상 유지보수 계약으로 나누고, 인프라 계정은 발주처 명의로 직접 결제하게 해야 납품 뒤 적자를 떠안지 않습니다.
