# 클로드 코드에 깃허브 저장소 주소를 주고 스킬을 설치했다면, 설치한 그 세션에서는 스킬이 바로 보이지 않으므로 클로드 코드를 한 번 껐다 켜야 스킬 목록에 나타난다.

👤 한 사람이 말함 · 코드깎는노인

빈 폴더에서 클로드 코드를 열고 스킬의 깃허브 주소를 주며 설치해 달라고 하면 저장소 받기, 패키지 설치, 실행 환경 점검까지 알아서 해 준다. 다만 설치를 진행한 그 화면에서는 새 스킬이 목록에 뜨지 않는다. 설치가 끝났는데 스킬이 안 보인다고 다시 설치하지 말고, 클로드 코드를 종료했다가 다시 실행해 스킬 목록을 확인하면 된다. 설치 전에는 저장소 주소가 공식 안내와 같은지 먼저 확인해야 한다.
