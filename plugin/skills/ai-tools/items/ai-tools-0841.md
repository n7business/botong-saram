# 메일 에이전트를 구글 계정에 연결할 때 AI가 메일을 마음대로 보내지 못하게 하려면, 구글 로그인 뒤 권한 화면에서 발송 권한 체크를 풀어 읽기 전용으로 연결하거나 발송 전에 비밀번호를 입력하게 만들어야 한다.

👤 출처 1곳 · 레인 | AI 바이브코딩 (@Vibe_RaiN)

구글 로그인 뒤 나오는 권한 화면은 OAuth 출입증에 권한을 얼마나 줄지 묻는 화면입니다. 메일 발송 권한을 주기 싫으면 해당 체크를 풀면 되고, 읽기 전용으로만 연결할 수도 있습니다. 발송 권한을 줄 때도 발송처럼 위험한 작업에는 제한을 걸 수 있습니다. 예를 들어 보내기 전에 비밀번호를 입력하게 하는 식입니다. 화자는 권한을 전부 체크하고 발송까지 허용했지만, 계획 단계에서 '초안 저장만 할지, 확인 후 발송까지 할지'를 정하라고 했습니다.
