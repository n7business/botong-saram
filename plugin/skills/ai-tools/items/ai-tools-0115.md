# AI로 만든 대시보드·웹사이트가 누가 봐도 AI가 만든 것 같다면 Impeccable 스킬로 레이아웃을 먼저 설계하고, 이미 만든 화면도 다시 돌려 점수가 낮은 구역을 고친다.

👤 한 사람이 말함 · 레인 | AI 바이브코딩 (@Vibe_RaiN)

Claude가 만든 대시보드가 다 비슷해 보이는 것은 같은 SaaS 템플릿으로 학습했기 때문입니다. Impeccable은 코딩 에이전트에 디자인 기준을 주는 스킬로, 구역별 점수를 매기고 낮은 부분을 개선합니다. 내장 디텍터는 보라색 그라데이션, 바운스 이징, 회색 글씨, 작은 터치 영역 같은 AI 티를 규칙으로 잡아내며 LLM이나 API가 필요 없습니다. 새 화면은 만들기 전에 이 스킬로 레이아웃부터 잡고, 기존 화면은 스킬을 다시 돌려 보완합니다.
