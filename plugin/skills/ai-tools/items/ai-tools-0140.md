# AI에게 웹페이지 움직임을 부탁할 때는 '뿅·촤락' 같은 의성어 대신 '효과 이름 + 속도 + 시작 조건'(예: 카드가 화면에 들어올 때 스프링 애니메이션으로 0.4초 동안 살짝 튀어오르게)으로 말해야 원하는 움직임이 나온다.

👤 한 사람이 말함 · 코드깎는노인

'버튼은 뿅뿅하게'처럼 말해도 AI는 움직임을 넣어 주지만, 무엇이 어떻게 얼마나 빨리 언제 움직일지는 AI가 짐작해서 채웁니다. 페이드, 슬라이드(방향 포함), 스프링, 카운트업, 마키, 스플릿 텍스트 리빌처럼 움직임에는 대부분 정확한 이름이 있습니다. 이름에 속도(0.4초 등)와 시작 조건(화면에 들어올 때, 결제가 끝나면 등)을 붙이면 나와 AI가 같은 움직임을 떠올립니다. 용어를 다 외울 필요는 없고 필요할 때 치트 시트에서 찾아 쓰면 됩니다.
