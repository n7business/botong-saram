# 채팅으로 앱을 만들다가 클로드 코드 같은 AI 코딩 도구로 옮길 때는 시작 전에 작업 폴더를 통째로 복사해 백업하고, 고치기 전에 허락을 받도록 모드를 Manual로 두어야 한다.

👤 출처 1곳 · 윤자동 | AI자동화로 세상을 돕는중 (@yun_ja_dong)

파일 한두 개짜리 앱을 조금씩 고치는 일은 채팅이 오히려 편하니, 지금 방식이 불편하지 않으면 코딩 도구를 깔지 않아도 됩니다. 이럴 때 옮기세요. 코드를 복사해 붙이는 일이 귀찮을 때, 파일이 늘어 하나를 고치면 다른 파일도 바꿔야 할 때, 에러를 AI가 직접 읽고 고치게 하고 싶을 때입니다. 이런 도구는 내 컴퓨터 폴더의 파일을 AI가 직접 고칩니다. 그래서 시작 전에 작업 폴더를 백업하고, 입력창 아래 모드를 Manual로 두어 고치기 전에 허락을 받게 하세요. 검은 터미널 창이 꺼려지면 VS Code 확장으로 써도 됩니다.
