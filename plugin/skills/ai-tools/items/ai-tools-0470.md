# AI에게 'API 키나 인증 파일은 읽지 말라'고 지침이나 스킬로 적어 두는 것만으로는 실제 접근을 막을 수 없으므로, 자격증명은 작업 폴더 밖에 두거나 권한 설정으로 막고 코드나 대화에 직접 넣지 말아야 한다.

👤 한 사람이 말함 · 요즘IT

API 키·토큰·인증 파일은 서비스에 바로 접근할 수 있는 수단이라 따로 관리해야 합니다. 지침 파일이나 스킬에 '읽지 마라'라고 적으면 AI가 참고는 하지만, 실행을 기술적으로 막는 것과는 다릅니다. 자격증명을 코드나 대화에 붙여 넣지 말고, 에이전트가 접근하지 못하는 곳에 두거나 권한 설정으로 막으세요. 삭제·배포처럼 영향이 큰 행동에도 지침과 별도로 권한 제한과 사람의 확인 절차를 남겨 두어야 합니다.
