# 세금계산서 발행, 외부 쇼핑몰 주문 가져오기, 소셜 로그인처럼 외부 시스템과 연결하는 일은 AI로 사내 화면을 만드는 직원에게 맡기지 말고 개발자가 마지막까지 맡아야 한다.

👤 출처 1곳 · 요즘IT

우리 시스템 안에서 하는 일과 달리 외부 연동은 상대 쪽 규칙을 읽고 맞춰야 합니다. 그래서 개발을 모르는 직원이 가장 어려워하는 영역입니다. 이 사례에서도 화면 만들기와 데이터 이전은 직원들에게 넘어갔지만, 외부 연동은 계약 종료를 앞둔 시점까지 넘기지 못했습니다. 외주 계약을 할 때 외부 연동은 누가 맡고 언제 넘길지 따로 정해 두세요.
