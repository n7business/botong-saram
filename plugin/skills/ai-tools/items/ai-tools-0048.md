# ChatGPT 프로·비즈니스 구독자는 오픈AI 설정의 빌링에서 'API 크레딧 청구하기'를 직접 눌러 신청해야 매달 최대 500달러 상당의 API 크레딧을 받을 수 있다.

👤 한 사람이 말함 · 조코딩 JoCoding

오픈AI는 프로·비즈니스 구독자에게 매달 최대 500달러 상당의 API 크레딧을 준다. 자동으로 들어오는 것이 아니라 공식 홈페이지 설정 → 빌링에서 'API 크레딧 청구하기'를 눌러 신청해야만 지급된다. 화자도 실제로 신청해 받았다. 받은 크레딧은 Decisions API 등 오픈AI API에 연결해 자동화·개발 실험에 쓸 수 있다. 구독만 하고 신청하지 않으면 그대로 날리는 혜택이니 구독 중이라면 매달 확인한다.
