# 사장이 직접 일하는 외식 매장은 사장 인건비를 뺀 인건비율을 15~19%로 유지해야 1년 뒤 반오토로 전환해도 인건비를 25% 선에서 맞출 수 있다.

👤 한 사람이 말함 · 장사는 김형철 (@장사는김형철)

화자는 사장이 직접 뛰는 동안 인건비가 19%를 넘지 않아야 한다고 본다. 직접 뛰는데도 20%대라면 반오토 전환 후에는 30%가 찍힌다는 것이 화자의 경험이다. 반대로 10%대 초반은 점주가 몸을 갈아 만드는 수치라 오래 유지할 수 없고, 고객을 제대로 챙기려면 최소 15%는 써야 한다고 말한다. 사장 근무를 몇 년씩 이어 가기는 어려우므로 1년 정도 자리 잡은 뒤 반오토 전환을 계획한다. 오토 매장을 15% 안팎으로 보는 기존 기준과 차이가 크므로 매장 형태와 근무 인원을 함께 놓고 판단한다.
