# 관리 비용은 월말에 한 번 보지 말고 10일 단위로 보고받아, 할인 같은 추가 비용이 있어도 전체 비용이 벌어지지 않게 관리한다.

👤 한 사람이 말함 · 수치 근거 · 장사는 김형철 (@장사는김형철)

화자는 10일·20일·30일마다 관리 비용 보고를 받는다. 지점이 여럿이면 점주들도 자기 관리 상태를 다른 지점과 비교할 수 있게 모두 공개한다. 강남점은 쿠폰 할인으로 매출의 약 4%가 빠지는데도 꼼꼼한 관리 덕분에 다른 매장과 비용 차이가 크지 않다고 한다. 수치는 화자 브랜드의 사례이므로 내 매장의 비용 구조에 맞춰 확인한다.
