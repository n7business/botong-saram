# 프랜차이즈를 고를 때는 직영점 출점이 계속 이어지는 브랜드와 대표가 가맹 상담을 직접 하는 브랜드를 우선 후보로 둔다.

👤 한 사람이 말함 · 장사는 김형철 (@장사는김형철)

돈이 안 되는 브랜드라면 본사가 직영점을 계속 낼 이유가 없습니다. 그래서 직영점이 계속 새로 생기는지가 수익성을 보여주는 간접 신호입니다. 가맹 상담을 대표가 직접 하는 브랜드도 나쁜 브랜드일 확률이 낮습니다. 다만 이 신호만으로 판단하지 말고, 기존 가맹점을 직접 찾아가 점주와 이야기해 보는 확인 절차를 함께 거칩니다.
