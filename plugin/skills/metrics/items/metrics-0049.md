# 사람 손이 많이 가는 자체 제조 공정은 투입 인원×시간을 원가로 환산해 보고, 레시피를 유지한 채 공장 OEM으로 넘기는 것이 싸면 전환한다.

👤 한 사람이 말함 · 자영업 다이어리 (@startupdiary2)

빵을 매일 직접 반죽하면 직원 세 명이 2~3시간씩 붙어야 해 그만큼 인건비가 원가에 올라간다. 사례 매장은 약 2년간 직접 만들다가 자체 레시피 그대로 공장에 OEM을 맡겨 1년째 납품받고 있으며, 받은 빵을 약 15분 굽는 공정만 남겼다. 전환 판단은 '자체 제조 인건비+재료비' 대 'OEM 단가+마무리 공정 비용'을 비교해서 한다. 맛의 차별점이 레시피에 있다면 OEM으로도 유지되므로, 손으로 하는 것 자체를 차별화로 착각하지 않는다.
