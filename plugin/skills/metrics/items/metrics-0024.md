# 부동산 중개수수료는 보증금·월세를 기준으로 계산기로 미리 시뮬레이션하고, 법정 중개보수 대상이 아닌 권리금에 대한 수수료 요구는 거절한다.

👤 한 사람이 말함 · 사군카페인 (@sa_caffeine)

인터넷에서 '중개수수료 계산기'를 검색해 보증금·월세 기준으로 복비를 미리 계산해 자금표에 넣는다. 권리금은 공인중개사법상 중개대상물이 아니어서 법정 중개보수 요율이 적용되지 않으므로, 권리금 기준으로 수수료를 요구하면 지급하지 않는다. 중개업소가 권리금을 부풀려 차액을 챙기는 사례(사장은 8천만 원에 내놨는데 1억에 팔고 2천만 원을 가져감)도 있으니 권리금은 이전 사장과 직접 금액을 확인한다. 권리금 알선 대가는 별도 서면 계약이 있을 때만 성립하므로, 서명한 적 없는 수수료는 내지 않는다.
