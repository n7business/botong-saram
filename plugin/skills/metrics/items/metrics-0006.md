# 새 사업 아이템을 고를 때는 네이버 키워드 광고 클릭 단가를 먼저 확인해, 클릭당 수천~만원대로 비싼 시장은 피하고 작지만 독점 가능한 틈새 시장을 선택한다.

👤 한 사람이 말함 · 아웃스탠딩

제품을 정하기 전에 네이버 검색광고 시스템에서 해당 키워드의 클릭당 단가(CPC)를 조회한다. 마케마케는 '탈모 샴푸' 키워드가 클릭 1회에 7,000~15,000원인 것을 보고 신생 소규모 업체가 광고비 싸움을 이길 수 없다고 판단해 진입을 미뤘다. 대신 검색 데이터로 더 작지만 경쟁자가 없는 '수영 샴푸' 시장을 골라 독점을 만든 뒤, 창업 2년 반 만에 매출 100억원을 넘겼다. 큰 시장은 자금이 쌓인 뒤 나중에 진입해도 늦지 않다. 단, 틈새 시장은 검색량 자체가 충분한지 함께 확인해야 한다.
