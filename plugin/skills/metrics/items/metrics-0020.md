# 매장 창업 사업계획의 초기 운영자금에 월세 6개월치와 직원 급여 3개월치를 넣어 두면, 초기 매출이 예상에 못 미쳐도 조급한 결정을 피하고 버틸 수 있다.

👤 한 사람이 말함 · 사군카페인 (@sa_caffeine)

월세 600만 원 매물이면 3,600만 원을 운영자금으로 잡고, 월 급여 총액이 1천만 원이면 3천만 원을 초도 비용에 미리 계산한다. 이 돈을 잡아 두지 않으면 장사가 기대만큼 안 되거나 다른 곳에서 손실이 났을 때 월세에 쪼들려 이상한 결정을 내리고, 직원에게도 여유 있게 대하지 못한다. 몇 개월치를 잡을지는 사장마다 다르게 정할 수 있고 6개월·3개월은 화자 개인의 기준이다. 권리금·보증금·인테리어가 초과되면 이 운영자금을 깎는 경우가 많으므로 장비 등급을 낮추는 쪽을 먼저 검토한다.
