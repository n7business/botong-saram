# 가족법인에 돈을 빌려줄 때는 차용증만으로는 부족하고 상환기간을 정해 실제 상환 내역을 남겨야 하며, 나중에 원금을 탕감하면 법인세와 주주 증여의제가 함께 걸린다.

👤 출처 1곳 · 이상화세무사의 모래세무 (@nicetax)

차용증만 있고 실제로 갚은 기록이 없으면 사실상 증여라는 공격을 받는다. 상환기간을 명시하고 실제 상환 내역을 기록해 둬야 한다. 빌려준 원금을 나중에 탕감하면 채무면제이익이 법인 익금이 되어 법인세가 붙는다. 같은 일로 주주에게 증여의제도 걸려 두 문제가 한꺼번에 생긴다. 가족이 법인 돈을 생활비로 쓰면 업무무관 가지급금이 되고, 일하지 않는 가족에게 준 급여는 손금으로 인정되지 않는다.
