# 총괄 코스트가 높게 나오면 메뉴별 코스트와 판매 구조를 따져 보고 남은 재고를 전수 조사해 과적재 여부를 확인한다.

👤 한 사람이 말함 · 장사는 김형철 (@장사는김형철)

메뉴 쪽에서는 수익이 나는 판매 구조로 팔고 있는지, 너무 퍼주기식으로 팔고 있지 않은지 확인한다. 원인을 모르겠으면 남아 있는 재고를 전수 조사한다. 화자는 보통 여기서 원인이 다 잡힌다고 말하며, 쓸데없이 쌓아 둔 재고를 발견하면 20일, 말일로 가면서 수치가 조정된다고 설명한다. 화자의 현장 경험이므로 두 가지를 확인해도 원인이 나오지 않으면 다른 요인도 함께 살핀다.
