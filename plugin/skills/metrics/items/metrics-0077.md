# 외식 매장의 총괄 원가율(주류·음료 포함, 물티슈 같은 비식자재 제외)은 평균 30%대로 관리하고 40%를 넘으면 운영 방식을 점검하는데, 반찬·소스를 기성품이나 본사 공급품으로 사서 일을 줄이면 원가율이 오른다.

👤 한 사람이 말함 · 장사는 김형철 (@장사는김형철)

원가율은 주류·음료까지 넣고 물티슈 같은 비식자재는 빼서 계산합니다. 평균 30%대가 정상 범위이고 40%는 넘지 않아야 할 상한선으로 둡니다. 40%를 넘으면 발주·조리·폐기 과정을 하나씩 뜯어봅니다. 흔한 원인은 반찬·소스를 기성품으로 사서 일을 편하게 하려는 것이어서, 간단한 반찬은 매장에서 직접 만드는 편이 원가 방어에 유리합니다. 추가 주문이 거의 없는 밥집은 고깃집보다 원가 방어가 어려우니 더 자주 확인합니다.
