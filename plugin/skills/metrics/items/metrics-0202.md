# 판촉용·이벤트용 '가짜 돈(페이크머니)'을 실제 지폐와 비슷한 크기로 만들면 '촬영소품'이나 'Copy'라고 작게 적어 넣어도 허용되지 않으며, 판매할 목적으로 만들거나 들여오면 형법상 통화유사물 제조죄로 처벌받을 수 있다.

🏛 공식 발표 · 한국은행 기업경영분석

지폐 모양 모조품은 실제 지폐 규격의 200% 이상이나 50% 이하로 만들거나, 실제 지폐와 쉽게 구별되는 소재를 써야 한다. 둘 중 하나만 갖추면 된다. 동전 모조품은 실제 동전 규격의 150% 이상이나 75% 이하여야 하고 금속 소재도 쓸 수 없다. 이쪽은 두 조건을 모두 갖춰야 한다. 실제 지폐와 크기가 비슷한 모조품에 '촬영소품, Prop money, Copy'처럼 작은 글씨를 넣은 것은 한국은행이 대표적인 위폐 사례로 본다. 모조품인 걸 알면서 사용하면 위조통화 지정행사죄(형법 제210조), 판매할 목적으로 제조·수입·수출하면 통화유사물 제조죄(형법 제211조)로 처벌받는다. 실제 크기에 가까운 모조품이 꼭 필요하면 반드시 한국은행 홈페이지 민원신청에서 사전 이용승인부터 받는다.
