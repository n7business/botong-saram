# 부대비용이 늘어난 지금 외식 매장의 총괄 코스트는 평균 30% 초반대로 관리하고 최대 35%를 넘기지 않아야 한다.

👤 한 사람이 말함 · 장사는 김형철 (@장사는김형철)

화자는 예전처럼 총괄 코스트 30%, 인건비 30%로 운영하면 요즘은 돈을 벌지 못한다고 본다. 고정비, 월세, 세무·노무 비용, 방역, 화재보험, 카드 수수료, 세금 같은 부대비용이 크게 늘었기 때문이다. 업종마다 차이는 있지만 30% 초반보다 낮으면 더 좋다고 본다. 40%를 넘으면 점검한다는 기존 기준보다 상한이 엄격하므로, 두 기준의 차이를 감안해 자기 매장의 순수익으로 확인한다. 화자의 경험에 근거한 기준이며 공식 통계는 아니다.
