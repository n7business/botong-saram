# 유입 문의에는 쌓아두지 말고 한 건씩 직접 전화해 요구사항을 듣고 제안서를 보내면 대부분 계약으로 이어진다.

👤 한 사람이 말함 · 클로브 블로그

플랫폼이나 검색으로 들어온 문의는 방치하면 쌓이기만 한다. 세무법인 예인 더케이는 미팅 신청 전부에 직접 전화해 상황을 듣고, 상담 내용을 토대로 제안서를 작성해 보냈더니 대부분 계약으로 전환됐다. 한 달이 되지 않아 신규 7건이 연결됐다. 전화 없이 문자·메일로만 응대한 건은 전환되지 않았다는 점에 주목한다. 소규모 서비스업이라면 문의 접수 당일 전화, 익일 제안서를 기본 루틴으로 둔다.
