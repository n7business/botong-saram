# 올해 쓴 서비스 대금을 내년에 지급하기로 했다면 돈이 나가는 시점과 상관없이 올해 비용과 미지급비용으로 잡아야 이익이 부풀려지지 않는다.

👤 한 사람이 말함 · 오늘부터 회계사 (@오늘부터회계사)

결산 때 출금 내역만 보지 말고, 올해 이미 받은 서비스 중 대금을 아직 치르지 않은 것이 있는지 확인합니다. 있다면 올해 비용으로 보고 미지급비용으로 잡습니다. 이를 빼면 올해 이익이 실제보다 좋게 보입니다. 매출 쪽도 같은 시점 문제가 있어, 돈을 받고 용역이나 물건을 이미 제공했는데 선수금으로 남겨 두면 매출이 낮게 나타납니다. 다만 선수금이 모두 매출이라는 뜻은 아니므로 실제 제공 여부를 건별로 따집니다.
