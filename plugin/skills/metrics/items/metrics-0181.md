# 회사를 팔 때 부채가 아주 크거나 재무상태가 나쁘면 매출과 이익이 좋아도 가격이 깎이고, 토지·공장 같은 부동산을 갖고 있으면 투자자가 긍정적으로 본다.

👤 출처 1곳 · 오늘부터 회계사 (@오늘부터회계사)

매수자는 매출과 이익뿐 아니라 부채와 재무상태도 따집니다. 부채가 지나치게 크면 실적이 좋아도 가격 할인 요소가 됩니다. 반대로 토지·공장 같은 부동산은 손실 위험을 막아 주므로 투자자가 긍정적으로 봅니다. 매각을 염두에 둔다면 몇 년 전부터 부채 수준을 관리합니다. 인증과 특허도 단기간에 돈으로 살 수 없는 자산이라 좋게 평가받습니다.
