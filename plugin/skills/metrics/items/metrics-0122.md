# 손님에게 받은 현금이 위조지폐인 것을 나중에 알았다면 거스름돈이나 거래 대금으로 다시 쓰지 말아야 하며, 알고 사용하면 2년 이하 징역 또는 500만 원 이하 벌금 대상이다.

🏛 공식 발표 · 한국은행 기업경영분석

받을 때 몰랐더라도 위조·변조 사실을 안 뒤에 사용하면 형법 제210조의 처벌 대상이 된다. 의심되는 지폐는 금고의 다른 현금과 섞지 말고 따로 빼 둔다. 거스름돈이나 거래 대금으로 내보내지 않는다. 행사할 목적으로 위조·변조 통화를 취득하면 제208조에 따라 5년 이하 징역 또는 1,500만 원 이하 벌금으로 처벌이 더 무겁다. 발견 후 처리 절차는 한국은행 홈페이지의 '위조지폐 발견시 처리요령' 메뉴에서 확인한다.
