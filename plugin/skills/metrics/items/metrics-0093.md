# 장사가 힘들어도 바로 완전 폐업하기보다 전대, 가족 위탁, 관리점장 채용으로 사장의 노동 투입량을 줄일 수 있는지 먼저 따져 본다.

👤 한 사람이 말함 · 아웃스탠딩

업력이 긴 편의점주들은 점포 운영이 힘들어지면 전대, 가족 위탁, 관리점장 채용으로 본인의 노동 투입량을 줄였고, 완전 폐업은 최악의 경우에나 택했습니다. 폐업을 결정하기 전에 이 세 방법을 각각 적용했을 때 매달 남는 돈과 사장이 일하는 시간을 비교해 봅니다. 상가를 직접 소유했다면, 한 점주처럼 담배권을 유지한 채 임차인에게 편의점 자리를 내주는 방법도 검토할 수 있습니다. 전대를 하려면 임대차계약과 임대인 동의 여부를, 가맹점은 가맹계약 조건도 먼저 확인해야 합니다. 이 내용은 편의점주들의 경험담이라 다른 업종에도 똑같이 통한다고 볼 수는 없습니다.
