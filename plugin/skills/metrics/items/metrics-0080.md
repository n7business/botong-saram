# 외식 매장 임대료(관리비 포함)는 매출의 5~6%를 기준선으로 보고, 8% 수준이 되는 비싼 자리는 피한다.

👤 한 사람이 말함 · 수치 근거 · 장사는 김형철 (@장사는김형철)

임대료는 관리비까지 합쳐 월매출 대비 비율로 계산합니다. 수익률 30% 이상 나온 매장들은 임대료가 매출의 5~6%였고, 권리금이 높은 메인 상권의 53평 매장은 8%로 순수익률이 17.8%까지 떨어졌습니다. 입지를 볼 때 예상 매출로 임대료 비율을 미리 계산해서 기준을 넘는 자리는 거릅니다. 메인 거리 대신 외곽으로 가도 권리금이 높을 수 있으니 권리금까지 같이 봅니다.
