# 직원이나 알바가 한 명이라도 있었다면 폐업일이 속한 달의 다음다음 달 말일까지 지급명세서를 제출해야 하며, 미제출 시 지급액의 1%(간이·일용근로 지급명세서는 0.25%) 가산세가 붙는다.

👤 한 사람이 말함 · 절세연구소 (김창휘 세무사)

폐업 시 그해 급여 지급 내역인 지급명세서를 세무서에 제출해야 하고, 기한은 폐업일이 속한 달의 다음다음 달 말일이다. 상용근로자 지급명세서를 내지 않으면 지급액의 1%, 간이지급명세서·일용근로소득 지급명세서는 0.25%가 가산세로 부과된다. 예를 들어 연 인건비 1억 원의 상용근로자 지급명세서를 누락하면 가산세가 100만 원이다. 마지막 달 급여의 원천세 신고와 4대보험 사업장 탈퇴(성립 소멸) 신고도 같은 시기에 함께 처리한다.
