# 정보통신공사업 기업진단에서는 설립 때 적은 자본금이 아니라 그동안 쌓인 손실·부채를 반영한 실제 자본을 보고 통신장비 판매 같은 겸업에 묶인 자산은 공사업 자본에서 빼므로, 은행 자료도 진단기준일과 조회기간에 맞춰 발급받아야 한다.

👤 한 사람이 말함 · 송진명 세무사 (@taxnode_song)

정보통신공사업 등록이나 유지를 위한 기업진단에서는 법인 설립 때 적은 자본금과 실제 자본 상태를 다르게 봅니다. 기존 회사라면 그동안 쌓인 손실과 부채를 반영한 자본을 기준으로 따집니다. 통신장비 판매를 겸한다면 판매 재고와 관련 채무 같은 겸업 내역을 따로 준비해야 합니다. 다른 사업에 묶인 자산을 전부 공사업 자본으로 볼 수는 없습니다. 은행 자료는 진단기준일과 조회기간에 맞춰 발급받으세요. 건설업에서 들은 예금 기간을 통신공사업에 그대로 적용하면 안 됩니다.
