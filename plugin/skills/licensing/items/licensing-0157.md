# 인허가처럼 여러 기관이 관련된 복합민원은 정부합동민원센터의 복합민원상담으로 처리절차·요건·담당부처를 먼저 안내받을 수 있으므로, 기관마다 따로 문의하기 전에 이 상담을 활용하는 것이 좋다.

🏛 공식 발표 · 국민신문고

정부합동민원센터는 여러 기관에 걸친 민원의 처리절차를 안내하는 복합민원상담과, 여러 분야 전문가와 공무원이 함께 보는 합동상담을 운영합니다. 상담관은 사실관계와 법적 관계를 관련 부처·전문가에게 확인한 뒤 상담합니다. 예시로 복합관광단지 개발 협의 절차, 여러 지자체에 걸친 하천구역 정비 주체 같은 질의가 안내되어 있습니다. 인허가에 여러 부처가 얽혀 담당기관이 분명하지 않을 때는 이 상담으로 절차·요건·형식과 담당부처를 먼저 정리한 뒤 민원을 내야 헛걸음을 줄일 수 있습니다.
