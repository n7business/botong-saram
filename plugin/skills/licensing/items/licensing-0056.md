# 공식 전자입국신고서 사이트는 www.e-arrivalcard.go.kr 하나뿐이고 수수료가 무료이므로, 결제정보를 요구하는 전자입국신고 사이트는 사칭 사이트라서 이용하면 안 된다.

🏛 공식 발표 · 하이코리아 (출입국·비자)

해외 거래처·바이어·외국인 직원을 한국으로 초청할 때 전자입국신고서 작성을 안내하게 되는데, 검색 상위에 뜨는 유사사이트가 수수료를 받고 신고를 대행하는 척하는 사례가 확인됐다. 법무부가 운영하는 공식 사이트는 www.e-arrivalcard.go.kr이며 전자입국신고 수수료는 무료다. 결제정보 입력을 요구하는 사이트는 공식 서비스가 아니므로 초청 안내문에 공식 주소를 직접 적어 보내고, 외국인 측이 결제 화면을 봤다면 바로 중단하도록 안내한다.
