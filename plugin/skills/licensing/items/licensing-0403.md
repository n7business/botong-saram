# 외국인근로자와 근로계약을 갱신하면 사업주는 늦어도 계약만료일 7일 전까지 고용허가 유효기간 연장허가를 신청해야 합니다.

🏛 공식 발표 · 고용허가제 EPS

처음 맺은 근로계약을 갱신하면 외국인근로자는 체류기간이 끝나기 전에 체류기간 연장허가를 받아야 합니다. 그래서 사업주는 늦어도 계약만료일 7일 전까지 고용허가 유효기간 연장허가를 신청해야 합니다. 제출서류는 외국인근로자고용허가기간 연장신청서와 갱신된 근로계약서 사본입니다. 근로자의 출입국 체류기간 연장 일정과 맞물리므로 계약만료일보다 넉넉히 앞서 신청하는 것이 안전합니다.
