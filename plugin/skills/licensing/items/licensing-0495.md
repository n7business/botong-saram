# 사회적협동조합, 사회적협동조합연합회, 이종협동조합연합회, 중소기업협동조합도 중소기업 범위에 들어가므로, 협동조합으로 사업하는 사람은 중소기업 지원사업 대상이 아니라고 단정하지 말고 중소기업확인서 발급을 검토해야 한다.

🏛 공식 발표 · 중소벤처24

중소기업 범위에는 사회적협동조합, 사회적협동조합연합회, 이종(異種)협동조합연합회, 중소기업협동조합이 들어갑니다. 협동조합 형태로 사업한다는 이유만으로 중소기업 지원에서 빠진다고 볼 필요가 없습니다. 비영리 사회적기업과 협동조합(연합회)에는 관계기업제도를 적용하지 않으므로, 출자 관계가 있어도 평균매출액을 합산하지 않습니다. 지원사업에 신청하기 전에 중소벤처24에서 중소기업확인서를 발급받아 자격을 확인하면 됩니다.
