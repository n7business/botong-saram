# 외국인근로자와 맺은 근로계약을 갱신하면 사업주는 늦어도 계약만료일 7일 전까지 고용허가 유효기간 연장허가를 신청해야 하므로, 만료 직전까지 미루면 근로자의 체류기간 연장에도 차질이 생긴다.

🏛 공식 발표 · 고용허가제 EPS

처음 맺은 근로계약을 갱신해 외국인근로자를 계속 쓰려면 고용허가기간을 연장해야 합니다. 근로자는 출입국관리법 제25조에 따라 체류기간이 끝나기 전에 체류기간 연장허가를 받아야 합니다. 그래서 사업주는 늦어도 계약만료일 7일 전까지 고용허가 유효기간 연장허가를 신청해야 합니다. 제출서류는 외국인근로자고용허가기간 연장신청서와 갱신된 근로계약서 사본입니다. 취업활동기간 만료 때 하는 재고용 신청과는 별개의 절차입니다.
