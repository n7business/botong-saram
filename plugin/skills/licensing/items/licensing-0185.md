# 정부24 비회원 로그인(개인)에서 사용자 정보를 직접 입력하는 경우 2026년 11월 10일부터 공동인증서·금융인증서가 인증 수단으로 추가되므로, 비회원으로 증명서를 떼던 사업자는 공동·금융인증서나 모바일 신분증·간편인증 중 하나를 미리 준비해야 한다.

🏛 공식 발표 · 정부24

정부24는 2026년 11월 10일(화)부터 비회원 로그인(개인)에서 사용자 정보를 직접 입력할 때 쓰는 인증 수단에 공동인증서와 금융인증서를 추가했습니다. 모바일 신분증과 간편인증은 그대로 쓸 수 있습니다. 정부24는 이 서비스를 쓰던 사람에게 적용일 전에 공동인증서나 금융인증서 같은 대체 인증 수단을 준비하라고 안내했습니다. 회원가입 없이 사업자등록증명이나 납세증명을 급하게 떼는 사업자는 필요한 날 막히지 않도록 인증서나 간편인증 앱을 미리 설치해 두는 것이 좋습니다. 공지에 직접 입력 방식이 어떻게 바뀌는지는 자세히 나와 있지 않으므로 실제 로그인 화면에서 한 번 확인해 두세요.
