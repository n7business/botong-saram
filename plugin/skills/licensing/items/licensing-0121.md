# 특허심판·행정심판·국세심판·감사원 심사청구·환경분쟁조정·노동위원회 판정과 조정 등은 다른 법률에 특별한 규정이 있는 사항으로 민원처리법 적용 제외 예시에 해당하므로, 이런 사안은 해당 법률의 절차를 따로 확인해야 한다.

🏛 공식 발표 · 국민신문고

민원은 다른 법률에 특별한 규정이 없으면 민원처리법을 따른다. 국민신문고 안내는 특허심판, 행정심판, 국세심판, 감사원 심사청구·재심의 청구, 환경 분쟁의 알선·조정, 노동위원회의 판정·조정, 국가인권위원회 진정을 제외대상 예시로 든다. 이런 사안은 일반 민원 절차와 구분해 해당 법률이 정한 절차를 확인해야 한다.
