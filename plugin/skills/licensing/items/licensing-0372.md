# 고용허가 사이트 전산 이용 문의는 1577-7114(한국고용정보원)로, 고용·노동 제도 문의는 국번 없이 1350(고용노동부)으로 받으며 둘 다 유료이고 평일 09:00~18:00에만 받습니다. 그러므로 외국인 고용 사업주는 문의 내용에 맞는 번호로 연락해야 합니다.

🏛 공식 발표 · 고용허가제 EPS

EPS 사업주 고용허가 서비스는 고용24(www.work24.go.kr)로 통합됐습니다. 홈페이지 로그인이나 전산 오류는 한국고용정보원 고객상담센터(1577-7114)에 문의합니다. 고용허가 요건이나 제도 해석은 고용노동부 고객상담센터(1350)에 문의합니다. 두 번호 모두 유료이고 평일 09:00~18:00에만 받습니다.
