# 정부24에서 결제한 민원을 신청인이 스스로 취소하면 결제 부가수수료는 돌려받지 못하고 나머지 금액만 환불되므로, 사업자는 민원 종류와 수량을 확인한 뒤 결제해야 한다.

🏛 공식 발표 · 정부24

정부24 민원을 신청인 뜻으로 취소하면 처리상태가 '취소'로 바뀌고, 부가수수료를 뺀 금액만 환불됩니다. 시스템 오류로 처리할 수 없어 '처리불가'가 된 경우에만 전액이 환불됩니다. 결제할 때 붙는 부가수수료는 최소 50원이고, 3,090원 이상이면 결제금액의 4%입니다. 수수료가 큰 민원을 잘못 신청했다가 취소하면 이 금액을 그대로 잃습니다. 서류 종류, 부수, 수령 방법을 확인한 뒤 결제하십시오.
