# 외국인 성명은 본국 여권 인적사항면의 기계판독영역(MRZ)을 기준으로 공백 포함 39자 안에서 성, 이름 순으로 적으므로, 외국인 직원의 성명을 근로계약서·4대보험 신고에 적을 때는 여권 MRZ의 순서와 철자에 맞춰야 한다.

🏛 공식 발표 · 하이코리아 (출입국·비자)

외국인등록증의 성명은 국제민간항공기구(ICAO) 여권 표준규격을 따릅니다. 본국 여권 인적사항면의 기계판독영역(MRZ)을 기준으로 공백 포함 39자 안에서 성, 이름 순으로 적습니다. 법무부가 외부 기관에 주는 인적정보도 이 실제 성명이므로, 사업장 서류의 이름 순서나 철자가 다르면 기관 전산 자료와 맞지 않을 수 있습니다. 채용할 때 여권 MRZ를 기준으로 성명을 한 번 확정하고, 모든 신고 서류에 같은 표기를 쓰는 것이 좋습니다.
