# 받을 돈 하나로 여러 은행 통장을 한꺼번에 압류 신청할 때는 은행마다 그 금액 전부가 묶이는 게 아니라, 받을 돈 총액 안에서 은행별 압류금액을 나눠 적어야 하고 꼭 똑같이 나눌 필요는 없다.

👤 출처 1곳 · 법무사 정승제 (@__jjjjjeee)

거래처에서 못 받은 돈으로 상대방의 여러 은행 예금을 압류하려면, 채권압류 신청서에 은행(제3채무자)별로 얼마를 압류할지 정해서 적습니다. 은행별 금액을 다 더하면 받을 돈 총액 안에 들어와야 합니다. 예를 들어 900만 원을 받아야 하면 A은행 500만 원, B은행 300만 원, C은행 100만 원처럼 나눌 수 있고, 300만 원씩 똑같이 나눌 필요는 없습니다. 상대방이 주로 쓰는 은행을 알면 그 은행에 금액을 더 많이 배정하는 편이 낫습니다.
