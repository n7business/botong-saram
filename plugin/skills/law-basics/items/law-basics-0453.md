# 1천만 원 미만 저작권 분쟁이나 조정안을 합리적 이유 없이 거부한 사건에서 조정부가 직권조정결정을 내렸을 때 결정서를 받은 날부터 2주 안에 불복 사유를 밝힌 서면으로 이의신청을 하지 않으면 확정판결과 같은 효력이 생긴다.

🏛 공식 발표 · 한국저작권위원회

저작권 조정부는 1천만 원 미만 소액사건이나 당사자가 조정안을 합리적 이유 없이 거부한 사건에 직권조정결정을 내릴 수 있습니다. 결정서를 받은 뒤 2주 안에 이의를 제기하지 않으면 그 결정은 재판상 화해, 즉 법원의 확정판결과 같은 효력을 갖습니다. 결정 내용에 동의할 수 없다면 송달받은 날부터 2주 안에 불복 사유를 구체적으로 적은 서면으로 이의신청을 하세요. 이의신청을 하면 직권조정결정은 효력을 잃습니다. 결정서를 받으면 송달일부터 기한을 바로 적어 두어야 합니다.
