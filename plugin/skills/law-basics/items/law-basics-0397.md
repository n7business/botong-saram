# 외주 개발을 맡길 때 저작권을 통째로 넘겨받지 않고 사용권만 받은 뒤 SW임치를 함께 계약하면, 비용을 아끼면서도 개발사가 폐업했을 때 유지보수에 쓸 소스코드를 확보할 수 있다.

🏛 공식 발표 · 한국저작권위원회

한국저작권위원회는 SW임치를 하면 저작권은 빼고 사용권만 넘겨받아 예산을 아낄 수 있다고 안내한다. 개발사는 원천기술 소유권을 지키고, 사용하는 쪽은 개발사가 폐업·파산하거나 재해로 소스코드가 없어졌을 때 수치기관에서 소스코드와 기술정보를 받는다. 저작권 양도 대가가 부담스럽다면 '사용권 + 임치' 구조를 검토할 만하다. 다만 임치물을 넘겨받는 조건(교부 조건)은 임치계약서에 분명히 적어 두어야 한다.
