# 법인이 해산하면 정관이나 주주총회에서 따로 정하지 않는 한 이사가 청산인이 되며, 청산인은 취임일부터 2주 안에 해산 사유와 연월일, 청산인의 성명·주민등록번호·주소를 법원에 신고하고 해산일(또는 선임일)부터 2주 안에 청산인 등기를 해야 한다.

👤 출처 1곳 · 헬프미 법률사무소 블로그

회사가 해산하면 정관에 다른 규정이 있거나 주주총회에서 다른 사람을 뽑은 경우를 빼고는 이사가 청산인이 됩니다. 청산인은 취임한 날부터 2주 안에 해산 사유와 연월일, 청산인의 성명·주민등록번호·주소를 법원에 신고해야 합니다. 해산된 날 또는 선임된 날부터 2주 안에 본점 소재지에서 청산인 등기도 해야 합니다. 청산인은 취임 후 지체 없이 재산상태를 조사해 재산목록과 대차대조표를 만들고, 주주총회 승인을 받은 뒤 법원에 제출해야 합니다.
