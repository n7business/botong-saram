# 홈페이지 메뉴·게시글 링크를 자바스크립트 함수(onClick)로만 만들면 네이버 검색로봇이 주소를 알 수 없어 안쪽 페이지를 수집하지 못하므로, 링크는 <a href="전체주소"> 형식으로 만들고 페이지 제목도 페이지마다 다르게 적어야 합니다.

🏛 공식 발표 · 네이버 서치어드바이저 가이드 (SEO 공식)

링크를 자바스크립트 함수로만 처리하면 검색로봇이 어떤 주소인지 정확히 알 수 없습니다. 그러면 그 뒤에 있는 다른 페이지들까지 찾아가지 못합니다. 링크는 표준 HTML의 <a href> 태그로 주소를 적어야 합니다. 본문 전체를 자바스크립트로 불러오거나 frame 태그로 감싸는 구조도 검색 반영에 불리하므로 일반 HTML을 쓰는 것이 좋습니다. 모든 페이지 제목을 똑같이 달지 말고, 각 페이지 내용의 주제를 정확히 설명하는 문구로 적어야 합니다. 검색에 나오는 문서 수가 적다면 제작업체에 이 항목들을 점검해 달라고 요청합니다.
