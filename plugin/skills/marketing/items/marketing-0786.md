# GEO 대행 계약서 부속 문서에는 계약이 끝날 때 질문 세트와 측정 이력 원본을 스프레드시트나 데이터 파일로, 콘텐츠 원본을 파일 일체와 저작권 귀속 문서로 돌려받는다는 조건과 반환 기한을 적어야 한다는 것이 GEO리드젠랩의 주장이다.

👤 출처 1곳 · 오픈애즈

화면 캡처로만 받으면 다음 업체가 데이터를 이어서 쓸 수 없습니다. 질문 세트·측정 이력·콘텐츠 원본이 발주사에 귀속된다는 점과 반환 기한을 계약서 부속 문서에 적어 둡니다. 그래야 업체를 바꿀 때 기준선을 처음부터 다시 만들지 않아도 됩니다. 계약 전에는 초기 인용 진단 리포트, 사이트 기술 점검 보고서, 선정 근거가 적힌 질문 세트 확정본 3가지를 받아 두어야 나중에 같은 기준으로 비교할 수 있습니다.
