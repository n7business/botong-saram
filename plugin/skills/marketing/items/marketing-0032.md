# '강남 ○○', '판교 ○○'처럼 지역명만 바꾼 페이지나 도메인을 여러 개 만들어 모두 같은 안내 페이지로 보내면 Google 도어웨이 악용으로 순위가 내려가거나 검색에서 빠질 수 있다.

🏛 공식 발표 · Google 검색 센터 문서 — 스팸 정책

특정 지역·도시를 겨냥한 여러 도메인이나 페이지를 만들어 사용자를 한 페이지로 유도하는 것은 Google이 명시한 도어웨이 악용 사례다. 홈페이지와 URL만 조금 다른 사이트를 여러 개 운영하는 것도 같은 위반이다. 실제 지점이 여러 곳이면 지점마다 주소·영업시간·사진 등 고유 정보가 담긴 페이지 하나씩만 두고, 지점이 없는 지역의 페이지는 만들지 않는다. 네이버에서도 비슷한 사이트를 여러 개 두면 불이익이 있으므로 사이트는 하나로 유지한다.
