# 생성형 AI로 독자에게 가치 없는 페이지를 대량으로 만들어 올리면 Google 확장된 콘텐츠 악용으로 사이트 전체가 순위 하락·검색 제외될 수 있다.

🏛 공식 발표 · Google 검색 센터 문서 — 스팸 정책

Google은 생성 방법과 관계없이 사용자에게 거의 가치가 없는 독창적이지 않은 페이지를 대량으로 만드는 것을 확장된 콘텐츠 악용으로 명시한다. 생성형 AI 도구로 가치 창출 없이 다량의 페이지를 생성하는 것, 다른 사이트 내용을 동의어로 바꿔 재게시하는 것, 검색 키워드만 들어 있고 독자에게 의미 없는 페이지가 예시다. 블로그·홈페이지에 AI로 글을 쓸 때는 우리 매장의 실제 경험·사례·가격 같은 고유 정보를 넣고, 발행 수보다 글 하나의 쓸모를 우선한다. 이미 올린 저품질 대량 페이지는 삭제하거나 검색에서 제외한다.
