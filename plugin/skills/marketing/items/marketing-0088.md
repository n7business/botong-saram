# 메타 DB(인스턴트 양식) 광고는 처음부터 캠페인 하나에 몰지 말고 캠페인 예산(CBO) 안에서 관심사·유사 타겟을 여러 광고 세트로 나눠 같은 소재를 돌려 픽셀을 학습시킨 뒤, 성과가 모이면 메인 캠페인 하나로 통합해야 문의 단가가 처음부터 낮게 나온다.

👤 한 사람이 말함 · 애드스트럭트 왕현 (@애드스트럭트)

DB 문의 광고를 시작할 때 캠페인 하나에 타겟 하나로 바로 시작하지 않는다. 캠페인 예산(CBO)으로 한 캠페인 안에 서로 다른 관심사 타겟과 유사 타겟을 각각 광고 세트로 두고, 광고 소재는 같은 것을 모든 세트에서 돌린다. 이 단계에서는 타겟 자체보다 같은 소재를 여러 세트에서 노출시켜 픽셀이 다양한 고객으로 학습하게 하는 것이 목적이다. 성과가 특정 세트로 모이면 광고를 메인 캠페인 하나로 몰아준다. 하루 10만 원 예산의 사례 계정은 이렇게 한 뒤 질문지를 바꿔 재세팅해도 문의당 6,000원 이하로 바로 시작했다.
