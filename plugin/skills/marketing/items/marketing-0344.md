# 네이버 검색에 맞추려면 사이트의 모든 페이지 제목을 똑같이 두지 말고, 페이지마다 콘텐츠 주제를 정확히 설명하는 문구로 적어야 한다.

🏛 공식 발표 · 네이버 서치어드바이저 가이드 (SEO 공식)

네이버 가이드는 중복 콘텐츠 점검 항목에서 모든 페이지의 제목을 동일하게 표현하지 말라고 안내합니다. 제목에는 해당 페이지의 콘텐츠 주제를 정확하게 설명하는 문구를 적습니다. 사이트 제목과 설명은 검색엔진이 엄격하게 관리하므로, 메인 페이지가 노출되지 않을 때는 정책 위반 항목이 없는지 HTML 마크업 가이드도 함께 확인합니다.
