# 스레드를 처음 시작할 때는 첫 5일 동안 자기소개 → 선택형 질문 → 동네 이야기 → 작업 증거 → 손님에게 받은 질문 답변 순서로 하루 한 개씩 올리면 막히지 않고 시작할 수 있다.

👤 한 사람이 말함 · 장사맛집 오팀장 (@장사맛집오팀장)

1일차에는 나이, 지역, 메뉴를 밝히고 스레드를 시작한다는 자기소개를 올립니다. 2일차에는 '영수증 리뷰 사진 1번, 2번 중 골라줘' 같은 선택형 질문을 올립니다. 3일차에는 우리 동네가 좋은 이유를 쓰고, 4일차에는 '아침 몇 시부터 육수를 끓이고 기름을 걷어내 총 3시간 걸린다' 같은 작업 증거를 올립니다. 5일차에는 주차장 위치와 1시간 주차 지원, 아기 의자 준비처럼 손님이 실제로 물어본 내용에 답합니다.
