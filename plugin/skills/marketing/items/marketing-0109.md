# 스레드에서 댓글과 조회수를 늘리려면 '뭘 고쳐야 돼?' 같은 추상적 질문이 아니라 '영수증 리뷰 사진 1번·2번 중 뭐가 좋아?'처럼 대답하기 쉬운 선택형 질문을 던져야 댓글을 쓰는 동안 체류 시간이 올라간다.

👤 한 사람이 말함 · 장사맛집 오팀장 (@장사맛집오팀장)

질문 글은 조회수가 잘 나오는 방법이지만 질문 형태가 중요하다. 추상적이고 열린 질문에는 댓글이 달리지 않는다. 두 가지 사진 중 고르기, 디저트 중 더 예쁜 것 고르기처럼 보는 사람이 1초 만에 답할 수 있는 선택형으로 묻는다. 댓글을 쓰는 시간만큼 게시물 체류 시간이 늘어 노출에 유리해진다. 처음 5일 글 중 둘째 날 주제로 쓰기 좋다.
