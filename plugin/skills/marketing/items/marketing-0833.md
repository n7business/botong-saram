# 스레드에서 팔로워는 정보 글, 공감 글, 재미 글 순으로 잘 늘며, 글은 나 중심 1인칭보다 읽는 사람이 반응하게 2~3인칭으로 써야 한다는 것이 빌리쌤의 주장이다.

👤 출처 1곳 · 빌리쌤 (@billy___ssam)
