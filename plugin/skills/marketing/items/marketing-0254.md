# AI로 만든 디자인에서 글자 위치를 살짝 옮기는 정도의 미세 조정은 프롬프트로 다시 시키면 전혀 다른 결과가 나올 위험이 있으므로 편집 기능으로 직접 고쳐야 한다.

👤 한 사람이 말함 · 마케터은진 (@success_eunjin)

화자는 고칠 부분을 프롬프트로 요청할 수도 있지만, 미세 조정까지 다시 시키면 결과물이 전혀 달라질 위험이 있다고 말합니다. 폰트 위치를 오른쪽으로 살짝 옮기는 정도라면 편집 버튼을 눌러 직접 수정합니다. 메타 광고 소재에서도 모델과 글자가 겹치는 부분을 조금씩 조정해 마무리했다고 합니다. 이는 젠스파크 사용 후기이므로, 쓰는 도구에 직접 편집 기능이 있는지 먼저 확인해야 합니다.
