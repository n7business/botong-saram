# 다른 사이트의 글·이미지·영상을 출처 표시나 내 의견 없이 그대로 옮기거나 동의어만 바꿔 다시 올리면 Google의 스크래핑 스팸에 해당합니다.

🏛 공식 발표 · Google 검색 센터 문서 — 스팸 정책

Google은 검색 순위를 노리고 다른 사이트 콘텐츠를 가져와 올리는 것을 스크래핑 스팸으로 봅니다. 내 내용이나 가치를 더하지 않거나 원본 출처를 밝히지 않고 다시 올리는 것, 동의어 교체나 자동화 도구로 조금만 고쳐 복사하는 것이 여기에 해당합니다. 다른 사이트의 콘텐츠 피드를 그대로 재생산하거나, 남의 동영상·이미지를 부가 가치 없이 모아만 둔 사이트도 마찬가지입니다. 남의 콘텐츠를 쓸 때는 출처를 밝히고 내 해설이나 적용 사례를 함께 실어야 합니다.
