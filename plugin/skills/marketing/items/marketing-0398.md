# 자사몰 광고비를 쓰기 전에는 구매가 메타로 제대로 측정되는지와 비회원 구매 차단 같은 구매 장벽이 없는지부터 확인해야 한다는 것이 화자의 주장이다.

👤 한 사람이 말함 · 수치 근거 · 애드스트럭트 왕현 (@애드스트럭트)

화자의 사례에서는 대행사가 설치한 API 오류로 구매 데이터가 메타에 제대로 전달되지 않았다. 실제 구매가 일어나도 픽셀이 안 샀다고 판단하면 좋은 타겟을 안 살 사람으로 분류하고, 메타가 틀린 정보를 계속 학습해 구매 안 할 사람 쪽으로 광고를 보낸다고 설명한다. 화자는 이를 광고를 안 돌리는 것보다 나쁘다고 평가했다. 조치는 픽셀을 재설계해 러닝을 처음부터 다시 시작하고, 회원에게만 판매하던 정책을 폐기해 비회원 구매를 여는 것이었다. 3~7월 전체 ROAS 0.33이던 브랜드가 1.7까지 회복해 2를 넘어가는 중이라고 한다. 측정 수정과 정책 변경을 함께 했으므로 각각의 효과를 따로 구분할 수는 없다.
