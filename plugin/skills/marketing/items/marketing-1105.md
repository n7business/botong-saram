# 스레드 본문에 외부 링크를 넣으면 조회수가 크게 떨어지므로, 링크는 본문 말고 댓글에 넣어야 덜 떨어진다는 것이 빌리쌤의 주장이다.

👤 출처 1곳 · 빌리쌤 (@billy___ssam)

스마트스토어나 예약 페이지 같은 외부 링크를 스레드 본문에 넣으면 조회수가 크게 떨어진다고 합니다. 링크는 본문 말고 내 글에 단 댓글에 넣으면 덜 떨어진다고 합니다. 다만 댓글에 넣는다고 불이익이 아예 없어지는 것은 아니고 '덜하다'는 정도입니다. 전환이 꼭 필요한 글에만 링크를 다는 것이 좋습니다.
