# 홈페이지 내용을 모두 자바스크립트로 불러오거나 HTML frame 태그로 감싸면 네이버 검색에 반영되지 않을 수 있으므로, 메인 페이지와 중요한 내용은 일반 HTML 태그로 만들어야 합니다.

🏛 공식 발표 · 네이버 서치어드바이저 가이드 (SEO 공식)

네이버 서치어드바이저는 페이지 콘텐츠가 검색에 반영되지 않을 때 두 가지를 먼저 확인하라고 안내합니다. 하나는 모든 내용이 자바스크립트로 로딩되는 구조인지, 다른 하나는 내용이 frame 태그 안에 있는지입니다. 대부분의 검색엔진은 표준 HTML로 콘텐츠를 제공하기를 권장합니다. 메인 페이지처럼 중요한 페이지는 frame 대신 일반 HTML 태그를 쓰는 것이 좋습니다. 제작업체에 맡긴 홈페이지라면 이 두 가지를 직접 물어보세요.
