# 남의 블로그·커뮤니티 댓글이나 서명에 키워드를 넣은 내 사이트 링크를 남기고, 품질 낮은 디렉터리·북마크 사이트에 등록하거나 링크 자동 생성 프로그램을 쓰면 Google 링크 스팸에 해당합니다.

🏛 공식 발표 · Google 검색 센터 문서 — 스팸 정책

Google 스팸 정책은 '샌디에이고 피자 최고의 피자'처럼 키워드 링크를 붙인 포럼 댓글이나 서명을 링크 스팸의 예로 듭니다. 품질이 낮은 디렉터리·북마크 사이트 링크, 사이트로 가는 링크를 자동으로 만들어 주는 프로그램이나 서비스, 여러 사이트의 바닥글·템플릿에 널리 뿌린 링크도 같습니다. 이런 방식으로 링크를 늘린 사이트는 순위가 낮아지거나 검색에서 빠질 수 있습니다. 링크를 뿌려 주겠다는 백링크 대행 상품도 같은 이유로 피하는 것이 좋습니다.
