# 스레드 게시글은 삭제하지 말고 보관해야 하며, 반응이 좋았던 글은 보관해 두었다가 표현을 바꿔 다시 올려야 한다는 것이 빌리쌤의 주장이다.

👤 출처 1곳 · 빌리쌤 (@billy___ssam)
