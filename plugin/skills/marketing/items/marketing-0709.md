# 홈페이지를 네이버 검색에 제대로 올리려면 네이버 서치어드바이저 웹마스터도구에 사이트를 등록해 소유 확인을 하고, 최신 글 본문 전체를 담은 RSS와 XML 사이트맵을 각각 '요청-RSS 제출'과 '요청-사이트맵 제출'로 내며, robots.txt에도 사이트맵 위치를 적어 두어야 합니다.

🏛 공식 발표 · 네이버 서치어드바이저 가이드 (SEO 공식)

사이트맵은 수집해야 할 페이지 주소 목록을 담은 XML 파일입니다. 이미 수집되고 있는 사이트라도 검색로봇에게 추가 정보를 줘서 수집을 도울 수 있습니다. 사이트맵은 웹마스터도구 '요청-사이트맵 제출' 메뉴로 냅니다. RSS 피드에는 최신 글의 요약이 아니라 본문 전체를 담아 '요청-RSS 제출' 메뉴로 내세요. robots.txt에 'Sitemap: 전체주소/sitemap.xml' 한 줄을 넣어도 검색로봇이 사이트맵 위치를 알 수 있습니다.
