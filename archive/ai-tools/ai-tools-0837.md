에이전트 SDK로 만든 제품에 Claude 이름을 꼭 넣어야 하는 것은 아닙니다. 넣는다면 'Claude Agent'(드롭다운 메뉴에 권장), 이미 'Agents'라고 붙은 메뉴 안의 'Claude', 기존 에이전트 이름이 있을 때의 '○○ Powered by Claude'만 허용됩니다. 'Claude Code', 'Claude Code Agent'라는 이름과 클로드 코드를 흉내 낸 ASCII 아트나 디자인 요소는 금지됩니다. 내 제품이 Anthropic 제품처럼 보이지 않도록 자체 브랜드를 써야 합니다.
