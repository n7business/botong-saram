클로드 데스크톱 앱(macOS, 윈도우 x64·ARM64)에는 클로드 코드가 들어 있어서 CLI를 따로 설치할 필요가 없습니다. 앱을 실행해 로그인하고 Code 탭을 누르면 됩니다. 바뀐 내용(diff)을 화면으로 보고, 세션 여러 개를 나란히 돌리고, 반복 작업도 예약할 수 있습니다. 데스크톱 앱에서 클로드 코드를 쓰려면 유료 구독이 필요합니다. 설치 없이 바로 써 보고 싶다면 브라우저에서 claude.ai/code를 여는 방법도 있습니다.
