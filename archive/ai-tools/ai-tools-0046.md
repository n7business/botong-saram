PPT 디자인은 Claude가 ChatGPT보다 조금 낫지만, ChatGPT Work는 설정 없이 AI 이미지를 만들어 넣는 반면 Claude Code는 자체 이미지 생성이 안 된다. 이를 보완하려면 Claude Code에 'Codex CLI로 AI 이미지를 생성해 슬라이드에 넣게 세팅하고 싶다, 방법을 알려 줘'라고 요청해 Codex CLI를 설치하고 ChatGPT 계정으로 로그인한다. 각자 ChatGPT 계정의 이미지 생성 할당량을 쓰기 때문에 별도 API 비용이 들지 않는다. 추상적인 개념을 설명하는 슬라이드에 특히 유용하다. 이미지가 들어가면 'AI 티'가 덜 나고 슬라이드가 생생해진다.
