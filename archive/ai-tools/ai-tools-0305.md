레퍼런스 없이 PPT를 요청하면 테마와 구성은 설계해 주지만 별다른 특징 없는 디자인이 나옵니다. 화자는 잘 알려진 기업들의 레이아웃을 정리한 GitHub 오픈소스 '겟디.md'를 자주 씁니다. 저장소를 복사하거나 다운로드한 뒤 Collection에서 원하는 브랜드의 사용 부분을 복사해 채팅에 붙여 넣습니다. 그러면 별도 명령어나 프롬프트 없이도 폰트, 버튼 크기, 색상 같은 디자인 요소가 PPT에 적용된다고 설명합니다.
