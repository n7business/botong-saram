구독 하나는 API 조직 하나에만 연결되고, API 조직도 한 번에 하나의 연결만 받는다. 연결 후 변경은 OpenAI 지원팀 문의가 필요하고, 바꿔도 크레딧 이전이나 추가 지급은 보장되지 않는다. 신청 전에 ChatGPT와 API에 같은 이메일을 쓰는지, 구독 소유자이면서 연결할 API 조직의 소유자인 계정인지, 그 조직의 결제 관리 권한이 있는지 확인한다. 팀이나 회사 조직이 따로 있으면 어느 조직에 붙일지 결정한 뒤 버튼을 누른다. 비즈니스 플랜은 워크스페이스와 API 조직을 모두 소유한 사람만 신청할 수 있고, 팀원은 API 조직·프로젝트 접근 권한을 따로 받아야 쓸 수 있다.
