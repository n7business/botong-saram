분석 툴에 쌓이는 클릭 기록은 우리 서버가 아닌 다른 회사 서버로 간다. 도입 전 확인할 것은 여섯 가지다. ① SOC 2 Type II·ISO 27001 같은 제3자 감사 인증 ② 이름 대신 내부 번호로 사용자를 구분하고 화면 정보를 가릴 수 있는지 ③ 2단계 인증·SSO·사람별 접근 범위 분리(암호화만으로는 계정 탈취를 막지 못함) ④ 데이터 저장 위치 선택 가능 여부 ⑤ 사용자 삭제 요청 처리와 보관 기간 설정 ⑥ DPA에 보안 사고 통보 방식·기한, 협력 업체 목록, 계약 종료 후 삭제 의무가 있는지. 툴의 보안만큼 '우리가 불필요한 정보를 습관적으로 보내고 있지 않은지'도 점검하고, 1년에 한 번 같은 기준으로 최신 인증 보고서를 다시 요청한다.
